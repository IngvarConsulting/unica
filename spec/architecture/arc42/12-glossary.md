# 12. Глоссарий

Термины перечислены по алфавиту. Определение даётся в том значении, в котором
термин употребляется в этом корпусе; если у термина есть нормативное следствие,
оно живёт в [реестре инвариантов](../invariants.md), а не здесь.

- **Adapter** — типизированная внутренняя граница вокруг движка: поставляемого
  CLI-инструмента, внешнего MCP-endpoint или скрытого сервиса. Имя адаптера
  никогда не видно модели.
- **Bootstrap** — нативный бинарник `unica-bootstrap` из тонкого пакета. Выбирает
  цель, скачивает и проверяет runtime, устанавливает его атомарно и запускает
  публичный MCP-процесс.
- **Cache impact** — набор кешей, которые доменное событие объявляет
  недействительными или требует обновить; вычисляется оркестратором, а не
  адаптером.
- **DCS** — домен схем компоновки данных 1С (data composition schema).
  Каноническое имя домена и инструментов `unica.dcs.*` зафиксировано ADR-0011;
  прежнее именование выведено из обращения и запрещено в активных документах.
- **Domain event** — типизированный факт, который операция сообщает о своём
  результате, например `FormChanged`. Основание для инвалидации кеша.
- **Dry run** — режим предпросмотра мутирующей операции: отчёт о том, что
  изменилось бы, без записи файлов и без записи состояния кеша. Значение по
  умолчанию для мутирующих операций.
- **EDT** — 1C:Enterprise Development Tools. Один из двух форматов исходников
  конфигурации, отличный от platform XML; формат — свойство source set, а не
  рабочего пространства.
- **Host** — приложение, которое загружает плагин и предоставляет модели
  MCP-инструменты: Codex CLI или Claude Code. Оба обслуживаются одним каталогом
  плагина (ADR-0012).
- **MCP** — Model Context Protocol.
- **Orchestrator** — Rust-сервер `unica`: владеет диспетчеризацией публичных
  инструментов, состоянием рабочего пространства и координацией кеша.
- **Parity fixture** — донорская эталонная модель под `tests/fixtures`, по
  которой сверяется поведение нативного обработчика. Не является путём
  исполнения.
- **Platform facade** — граница в `infrastructure/platform/`, за которой заперт
  весь OS-специфичный код; остальные слои не содержат условной компиляции по
  операционной системе (ADR-0009).
- **Public MCP server** — единственный сервер, видимый модели через
  `.mcp.json`. Всегда ровно один, всегда с именем `unica`.
- **Redaction** — потоковое маскирование значений строк подключения, паролей,
  токенов и секретов в захваченном выводе перед его попаданием в результат
  операции.
- **Registry entry** — запись реестра инвариантов (`INV-*`) или требований к
  качеству (`REQ-*`): правило, решение-основание, проверка и контур действия.
  Цитируется по ID в описании PR и в ревью.
- **RLM** — поставляемый набор инструментов навигации по коду `rlm-tools-bsl`
  (бинарники `rlm-tools-bsl` и `rlm-bsl-index`) и его персистентный индекс.
  В этом корпусе «RLM» всегда означает эти инструменты и их индекс; версии
  фиксируются в `plugins/unica/third-party/tools.lock.json`.
- **Skill** — инструкция операции под `plugins/unica/skills`, одинаковая для
  обоих хостов. Маршрутизирует пользователя к инструментам `unica.*`, а не к
  внутренним движкам.
- **Source root** — корень выбранного source set, внутри которого операция
  читает и пишет файлы. Выбирается детерминированно и одинаково всеми
  инструментами сессии.
- **Source set** — именованный набор исходников с одним эффективным форматом.
  Рабочее пространство может содержать несколько source set с разными
  форматами.
- **Support guard** — fail-closed проверка состояния поддержки объекта перед
  нативной мутацией: нечитаемый или повреждённый маркер поддержки блокирует
  мутацию, а не трактуется как «не на поддержке».
- **Thin package** — публикуемый пакет маркетплейса, содержащий метаданные
  плагина и нативные bootstrap-бинарники, но не полный runtime (ADR-0008).
- **Workspace epoch** — лёгкий отпечаток рабочего пространства, связывающий
  состояние кеша с текущим checkout. Связанный worktree получает собственную
  идентичность.
- **Workspace service** — скрытый сервис, удерживающий тёплое состояние
  анализатора или индекса для пары «корень рабочего пространства + source
  root». Не является публичной MCP-регистрацией.
