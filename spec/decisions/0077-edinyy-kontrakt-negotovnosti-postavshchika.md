# ADR-0077: Неготовность поставщика имеет один типизированный словарь

- Статус: `accepted`
- Дата: `2026-08-22`
- Задача: [#401](https://github.com/IngvarConsulting/unica/issues/401)

## Контекст

Поиск и диагностика наблюдают одно переходное состояние: поставщик принят и
работает, но его индекс или снимок результатов ещё не готов. Поиск публиковал
`dependencyPending`, но терял срок повтора; диагностика использовала частные
коды. Агенту приходилось разбирать текст и строить собственную политику.

Происхождение выбора записано в
[проектной записке](../../docs/design/2026-08-22-provider-not-ready-contract-design.md).

## Решение

1. `unica.code.search` и `unica.code.diagnostics` выражают переходную
   неготовность общими полями `code=dependencyPending`, `retryable=true`,
   непустым `detailCode` и необязательными `retryAfterMs` и `state`.
2. `retryAfterMs` публикуется только когда его сообщил поставщик; Unica не
   назначает срок повтора самостоятельно.
3. Идентификатор поставщика остаётся во внешней секции. Человекочитаемая
   диагностика не заменяет типизированный код и не определяет ветвление.
4. Для `unica.code.diagnostics` неготовность дополнительно несёт
   `nextAction=status`. Немедленный `findings` после `analyze` возвращает этот
   переходный исход либо терминальные результаты диагностики, но не постоянную
   недоступность.
5. Поиск сохраняет ограниченное ожидание ролей внутри исходного вызова по
   ADR-0056. Диагностика отвечает неготовностью без дополнительного ожидания;
   новый входной параметр и отдельная публичная операция ожидания не вводятся.
6. Готовый путь не выполняет опросов и не получает дополнительной задержки.

Запись уточняет контракт завершения ADR-0056 и заменяет частные коды
неготовности диагностики из ADR-0045; остальные решения этих записей
сохраняются.

## Последствия

Вызывающая сторона использует один словарь для поиска и диагностики, сохраняет
подсказку поставщика и может явно выбрать `action=status` для диагностики.
Старые частные коды диагностики больше не являются публичным признаком
переходной неготовности.
