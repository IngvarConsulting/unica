# ADR-0077: Обычное клиентское приложение входит в закрытый контракт свойств общего модуля

- Статус: `accepted`
- Дата: `2026-08-22`
- Задача: [#609](https://github.com/IngvarConsulting/unica/issues/609)

## Контекст

ADR-0025 задаёт закрытые формы операций `unica.meta.add` и `unica.meta.edit`,
но первоначальный домен свойств общего модуля не включал платформенное поле
`ClientOrdinaryApplication`. В результате корректный флаг нельзя было изменить
через публичную поверхность, хотя независимый read-профиль `meta.info` уже мог
его наблюдать. Основания изменения записаны в
[проектной записке](../../docs/design/2026-08-22-common-module-ordinary-client-property-design.md).

## Решение

1. Boolean-свойство `ClientOrdinaryApplication` входит в закрытый домен
   `setProperties` только для владельца `CommonModule` и публикуется одинаково
   в схемах `meta.add` и `meta.edit`.
2. Предварительный просмотр и применение используют один механизм записи и
   один цикл записи и чтения XML; отдельного файлового или DSL-маршрута для
   этого свойства нет.
3. Профиль чтения остаётся независимым от закрытого перечня записи по ADR-0042.
   Наличие свойства в мутации не создаёт второй маршрут его наблюдения.
4. Неизвестное имя свойства отклоняется с точным полем и перечислением всех
   поддержанных для вида владельца альтернатив, выведенным из того же закрытого
   реестра, который выполняет мутацию.

## Неграницы

1. Решение не добавляет новый инструмент, файловый селектор или ручной
   XML-маршрут.
2. Решение не связывает полный read-профиль `meta.info` с закрытым allowlist
   writer и не объявляет остальные платформенные свойства редактируемыми.
3. Решение не меняет форму результата, транзакционный контракт или профиль
   Platform XML 8.3.27/2.20.

## Последствия

- Общий модуль можно атомарно создать или изменить с флагом обычного клиентского
  приложения без ручного редактирования XML.
- Подсказка при опечатке отражает фактический домен конкретного вида метаданных.
- Публичная схема расширяется совместимым необязательным полем, а набор
  инструментов и форма результата не меняются.

## Верификация

- `crates/unica-coder/src/domain/metadata/properties.rs` проверяет точный текст
  и поле диагностики неизвестного свойства;
- `crates/unica-coder/src/domain/metadata/info_properties.rs` удерживает
  независимый маршрут чтения;
- `crates/unica-coder/src/application/metadata.rs` проверяет одинаковую
  boolean-схему и публичную диагностику обеих мутаций;
- `crates/unica-coder/src/application/meta_add_surface_tests.rs` проверяет
  add/edit, preview/apply и XML round-trip `ClientOrdinaryApplication`.
