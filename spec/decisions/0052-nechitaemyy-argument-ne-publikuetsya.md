# ADR-0052: Аргумент, которого не читает ни один обработчик, не публикуется

- Статус: `accepted`
- Дата: `2026-08-11`
- Задача: [#315](https://github.com/IngvarConsulting/unica/issues/315)

## Контекст

Общий список `NATIVE_XML_DSL_ARGS` попадает в схему почти каждого нативного
XML-инструмента. Тринадцать имён в нём собственные описания называли
нерабочими прямо в тексте: «Declared argument that no handler reads».

Цена двойная. Схема инструмента грузится агентом целиком, и мёртвые записи
вытесняют из окна контекста то, ради чего вызов делается. А вызывающий,
передавший такое имя, получает молчание вместо отказа: аргумент принимается
схемой и нигде не читается, поэтому ошибка обнаруживается по отсутствию
эффекта, а не по сообщению.

ADR-0048 вывел это правило для восьми типизированных читателей. Здесь оно
распространяется на весь общий список.

## Решение

1. Аргумент, которого не читает ни один обработчик, из публичной схемы
   снимается. Его описание снимается вместе с ним: описание без публикующего
   инструмента — запись о том, чего нет.
2. Снятие такого имени — намеренный разрыв совместимости, а не побочный эффект
   чистки. Вызов, передававший его, теперь отвергается как неизвестный
   аргумент, и это лучше прежнего молчания: вызывающий узнаёт об ошибке сразу.
3. Проверка закрепляет снятые имена таблицей, а не выводит их из описаний.
   Оракул, построенный из тех же данных, которые изменение удаляет,
   становится пустым вместе с ними и перестаёт что-либо удерживать.
4. Дополнительно ни один опубликованный аргумент не описан как нечитаемый.
   Это второе, независимое утверждение: оно закрывает класс, а таблица из
   пункта 3 — конкретные имена.

## Неграницы

1. Решение не сужает схемы инструментов до их собственных параметров. Общий
   список остаётся у писателей; это отдельная работа, оставленная в #315.
2. Решение не снимает дублирование имён в двух регистрах (`FormPath` и
   `formPath`). Это снятие работающего контракта, а не мёртвой записи, и
   требует своего решения о совместимости.
3. Решение не касается аргументов `unica.build.*`: их владелец — ADR-0051.

## Последствия

1. Схема каждого нативного XML-инструмента уменьшается на двадцать шесть
   записей — тринадцать имён в двух регистрах.
2. Вызов, передававший снятое имя, ломается. Поведение при этом не меняется:
   аргумент и раньше ни на что не влиял, менялось только то, узнаёт ли о нём
   вызывающий.
3. Проект принимает на себя обязанность держать таблицу снятых имён в
   проверке. Она не выводится и требует правки при следующем снятии — это
   осознанная цена за то, чтобы проверка не могла опустеть сама.

## Верификация

- `cargo test --package unica-coder --lib no_published_argument_is_described_as_unread`
  — ни один из тринадцати снятых аргументов не публикуется ни одним
  инструментом, и ни один опубликованный аргумент не описан как нечитаемый.
- `cargo test --package unica-coder --lib described_arguments_are_still_reachable`
  — у каждого оставшегося описания есть публикующий инструмент.
- `python3 -m unittest discover -s tests/ci` — `test_ledger_matches_the_live_registry`
  удерживает соответствие ведомости живому реестру.
