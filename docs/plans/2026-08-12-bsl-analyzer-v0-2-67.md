# BSL Analyzer v0.2.67 Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Выпустить воспроизводимые трёхплатформенные assets `bsl-analyzer` `v0.2.67` и синхронно переключить на них поставляемый бинарник и Rust `parser`/`syntax` в Unica.

**Architecture:** Сначала `IngvarConsulting/unica-toolchain` закрепляет точный upstream tag и commit, проверяет source/licenses, собирает три target asset и публикует immutable release. Только после проверки опубликованных байтов Unica обновляет consumer lock, Rust git-revisions, атрибуцию и текущий provenance snapshot; публичная MCP-поверхность, stdio workspace service и CFE-модель не меняются.

**Tech Stack:** Python 3.12, GitHub Actions/CLI, Cargo/Rust 1.95.0, JSON manifests, Rust/Python contract tests, SHA-256, Markdown/NOTICE provenance.

## Global Constraints

- Upstream source: `https://github.com/itrous/bsl-analyzer`, annotated release tag `v0.2.67` (`562f9ebfe400fb9fbd8f913c2756bcfc551588d4`), peeled exact commit `9a92766691bbd0191a5ff02c34fa9058e4570b85`.
- Toolchain release identity: `bsl-analyzer-v0.2.67-build.1`; existing tags/releases are immutable and must not be moved or overwritten.
- Targets: `darwin-arm64`, `linux-x64`, `win-x64`; Unica lock changes only after all three assets are published and verified.
- Build the upstream package `bsl-analyzer` binary `bsl-analyzer-app`, normalized to asset base `bsl-analyzer`; do not substitute the smaller upstream comparison binary.
- License remains `LGPL-3.0-or-later`; the expanded upstream `NOTICE` from `v0.2.67` must replace the packaged `v0.2.62` notice.
- The bundled binary and in-process Rust packages `parser`/`syntax` must resolve to the same source commit.
- Keep one public MCP server `unica`; do not expose upstream HTTP transport, `ignored_authors`, supplier-diff scope, raw contract commands, or any other new `unica.*` surface.
- Keep the internal analyzer transport as warm stdio MCP behind the ADR-0018 workspace service.
- Treat upstream multi-root indexing, `root_id`, global unresolved-name search, and `--cache-dir` as compatibility inputs, not as new public Unica arguments or result fields.
- Prove the packaged single-root path with a real `unica.code.search` call whose `bsl-analyzer` section finds a fixture symbol.
- Do not implement or flatten dependency-aware CFE topology in this update.
- Unica's own plugin version and host manifests remain unchanged.
- Design owner: `docs/design/2026-08-12-bsl-analyzer-v0-2-67-design.md`; no new ADR or registry entry is required.
