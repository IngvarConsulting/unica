Как читать

Сигнал PR — сколько ждёт автор от push до вердикта гейта. Путь до вливания включает очередь слияния: она проверяет ровно то дерево, что ляжет в main, полным набором. Зелёный main считается по push после вливания, а ложный зелёный — это красный main при зелёной очереди по тому же коммиту: такого не должно быть никогда. Повторы — сколько тестов nextest перезапускал; выкидки — сколько постановок в очередь закончились без вливания.
