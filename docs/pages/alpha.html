Сборки alpha

Alpha — срез ветки main для проверки и для тех, кому нужна свежая Unica до кандидата. Сборка выходит ночью, когда main зелёный и сдвинулся, и ставится вручную, без маркетплейса. Гарантий нет: сборка может сломать проект, а следующая alpha заменит предыдущую без предупреждения.

Хранятся две последние alpha. Старые удаляются вместе с тегом, поэтому не закрепляйте номер надолго.

Чем alpha отличается от кандидата

  • Кандидат проходит проверки установки и раздаётся каналом unica-next. Его номер остаётся навсегда.
  • Alpha проверен тестами main и не проходит проверки установки из маркетплейса. Обновления сами не приходят, номер со временем исчезает.
  • Номера по SemVer alpha младше rc того же ядра, хотя содержимое может быть новее: сравнивайте срез main, а не номер.

Скачать и поставить

Архив содержит ядро и все движки: раннер и анализатор. Он распаковывается в каталог unica, и файлы должны оставаться на своих местах: ядро ищет движки рядом с собой.

Linux x64

curl -LO {{alpha_download}}/unica-full-linux-x64.tar.gz
tar -xzf unica-full-linux-x64.tar.gz
./unica/bin/linux-x64/unica --help

macOS на Apple Silicon

curl -LO {{alpha_download}}/unica-full-darwin-arm64.tar.gz
tar -xzf unica-full-darwin-arm64.tar.gz
./unica/bin/darwin-arm64/unica --help

Windows x64

curl.exe -LO {{alpha_download}}/unica-full-win-x64.tar.gz
tar.exe -xzf unica-full-win-x64.tar.gz
.\unica\bin\win-x64\unica.exe --help

Первая строка ответа --help называет версию: она совпадает с тегом без v.

Подключить к агенту

Ядро работает как MCP-сервер по stdio и берёт рабочую папку из каталога запуска. Укажите абсолютный путь к распакованному файлу:

claude mcp add unica -- /абсолютный/путь/unica/bin/linux-x64/unica
codex mcp add unica -- /абсолютный/путь/unica/bin/linux-x64/unica

Если что-то не так

Вернитесь на стабильную версию и опишите проблему в issue, указав тег alpha и срез main. Откатов и исправлений именно этой alpha не будет: исправление выйдет следующей.
