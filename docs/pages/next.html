Кандидаты выпуска

Канал next

Кандидат — сборка следующей версии, которую можно поставить до выхода и проверить на своих задачах. Кандидатов раздаёт отдельный маркетплейс unica-next. В стабильном каталоге их нет, поэтому канал подключается и отключается отдельно.

Сейчас в канале

{{next_tag}} Заметки о выпуске →
плагин unica@unica-next

В стабильном каталоге

{{stable_tag}} Заметки о выпуске →
плагин unica@unica

Канал получает кандидата вида X.Y.Z-rc.N после того, как тот прошёл проверки установки. Поэтому свежий пререлиз на GitHub может появиться здесь позже или не появиться вовсе.

Что понадобится

  • Агент и Git. Codex или Claude Code 2.1.69 и новее. Через Git ставится плагин, на Windows подойдёт Git for Windows. Node.js и Python не нужны.
  • Система. Windows x64, macOS на Apple Silicon или Linux x64.
  • Прямой доступ к GitHub. Первый запуск скачивает ядро, движки докачиваются при первом вызове, которому они нужны. Загрузчик не ходит через прокси и доверяет только вшитым корневым сертификатам. Если GitHub доступен только через прокси, ядро и движки можно скачать заранее, как описано в разделе «Сеть и данные».
  • Один плагин из двух. unica@unica и unica@unica-next запускают MCP-сервер с одним именем unica, поэтому установленным держите один из них.

Подключить канал

  1. Добавьте маркетплейс канала

    codex plugin marketplace add IngvarConsulting/unica-marketplace --ref next

  2. Удалите стабильный плагин

    Пропустите шаг, если стабильный плагин не установлен.

    codex plugin remove unica@unica

  3. Установите плагин канала

    codex plugin add unica@unica-next

  4. Проверьте версию

    codex plugin list

    В строке unica@unica-next в столбце VERSION должна стоять версия из карточки «Сейчас в канале»: {{next_version}}.

  5. Откройте новую задачу

    Codex подхватывает навыки и MCP-конфигурацию при старте задачи, уже открытая задача их не увидит. Первый старт подождёт, пока скачается ядро.

  1. Добавьте маркетплейс канала

    claude plugin marketplace add IngvarConsulting/unica-marketplace#next

  2. Удалите стабильный плагин

    Пропустите шаг, если стабильный плагин не установлен.

    claude plugin uninstall unica@unica

  3. Установите плагин канала

    claude plugin install unica@unica-next

  4. Проверьте версию

    claude plugin list

    У unica@unica-next должна стоять версия из карточки «Сейчас в канале»: {{next_version}}.

  5. Начните новую сессию

    Или выполните в текущей /reload-plugins. Навыки вызываются как /unica:<навык>, например /unica:meta-info, а команда /mcp показывает сервер плагина plugin:unica:unica. Первый старт подождёт, пока скачается ядро.

Обновление

Канал раздаёт самую свежую опубликованную версию: следующего кандидата, а после выхода версии и её саму. Обновляться до них нужно одинаково.

codex plugin marketplace upgrade unica-next
codex plugin remove unica@unica-next
codex plugin add unica@unica-next

Отдельной команды обновления плагина в Codex нет, поэтому плагин переустанавливается. Затем откройте новую задачу.

claude plugin marketplace update unica-next
claude plugin update unica@unica-next

Затем начните новую сессию или выполните /reload-plugins. Вместо ручного обновления можно включить автообновление: /plugin → Marketplaces → unica-next → Enable auto-update. Для сторонних маркетплейсов оно по умолчанию выключено.

Вернуться на стабильную версию

Вы получите версию из карточки «В стабильном каталоге»: {{stable_tag}}. Первая команда нужна, только если стабильный маркетплейс unica ещё не добавлен.

codex plugin marketplace add IngvarConsulting/unica-marketplace --ref main
codex plugin marketplace upgrade unica
codex plugin remove unica@unica-next
codex plugin add unica@unica

Codex ставит плагин из своей копии каталога, поэтому её сначала нужно обновить. Затем откройте новую задачу. Если канал больше не нужен, уберите его маркетплейс: codex plugin marketplace remove unica-next.

claude plugin marketplace add IngvarConsulting/unica-marketplace
claude plugin uninstall unica@unica-next
claude plugin install unica@unica

Затем начните новую сессию или выполните /reload-plugins. Если канал больше не нужен, уберите его маркетплейс: claude plugin marketplace remove unica-next.

Если что-то не так

  • Версия не та, что в карточке «Сейчас в канале». Обновите маркетплейс канала и плагин, как в разделе «Обновление». Если версия не сменилась, заведите issue.
  • Первый старт падает на загрузке ядра. Например, с ошибкой UnknownIssuer. Скорее всего, GitHub доступен только через прокси или HTTPS перехватывает антивирус: загрузчик так не работает. Обход описан в разделе «Сеть и данные».
  • Остался установленным стабильный плагин. Оба плагина запускают сервер unica. Удалите unica@unica, как во втором шаге установки.
  • Нашли ошибку в кандидате. Заведите issue и укажите версию из plugin list: так мы поймём, какой кандидат проверять.
