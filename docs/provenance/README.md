# Записи ревью происхождения

**Архивный материал планирования, а не источник истины.** Каждая запись в
`reviews/` датирована и описывает состояние донора и решение сопровождающего на
момент своей даты. Записи не обновляются: исправление задним числом стёрло бы
свидетельство того, что было решено тогда.

Поэтому в разрешении противоречий записи ревью не участвуют. Действующее
состояние происхождения читается из
[`spec/provenance/skill-upstreams.json`](../../spec/provenance/skill-upstreams.json),
действующее уведомление — из `plugins/unica/ATTRIBUTIONS.md`, версии и лицензии
поставляемых бинарников — из `plugins/unica/third-party/tools.lock.json`. Если
запись ревью расходится с любым из них, права запись ревью не имеет.

Записям разрешено содержать снятые с обращения имена операций, skills и путей:
это часть свидетельства. Контракты именования их сознательно исключают из
проверки.

Здесь же лежат backlog'и продуктовых обновлений — тот же класс материала: они
фиксируют намерение на дату, а не действующий контракт.

Новая запись добавляется, а не переписывает прежнюю. Процедура ревью и
сборочные команды описаны в
[`spec/provenance/README.md`](../../spec/provenance/README.md).
