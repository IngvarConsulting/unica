# Отказ от несовместимого формата предшествует записи

Проверка формата охватывает нативные и типизированные XML-операции до обработчика.
Отказ на старом или новом неподдерживаемом профиле сохраняет исходные байты;
отдельного пути миграции и параметра целевого формата нет.
