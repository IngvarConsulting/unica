# Остаток изоляции секций и полного порядка интерфейса

Остаётся обязательство для всех пяти операций: изменяется только своя
секция и выбранные элементы, соседние данные сохраняются. Порядок
принимается только полной последовательностью; частичный список отвергается.
Существующая проверка видимости не доказывает эти общие условия.
