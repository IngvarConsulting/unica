# Все кандидаты автообнаружения проверяются без перехода по ссылке

Каталог и его записи считаются кандидатами только как настоящие каталоги
без перехода по ссылке; определённо непригодное пропускается, а отказ,
оставивший вопрос без ответа, завершает дискавери ошибкой.
