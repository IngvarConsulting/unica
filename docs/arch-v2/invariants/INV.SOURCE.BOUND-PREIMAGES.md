# Изменение связано с исходными байтами или отсутствием файла

Каждый обработчик закрытого набора прежних XML-мутаторов связывает
с транзакцией байты фактического владельца, использованного входа
или проверенное отсутствие цели.
Изменение между планированием и публикацией отклоняет операцию
без перезаписи чужого результата.

Состав этого набора ещё не сопоставлен с текущими операциями `apply`.
