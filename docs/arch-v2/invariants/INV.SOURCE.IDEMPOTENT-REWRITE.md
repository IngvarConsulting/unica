# Повторный эквивалентный результат не заменяет файл

Для закрытого набора обработчиков повтор сохраняет байты и идентичность
файла. Набор требует сверки с текущими операциями канонического `apply`:
прежний агрегат проверяет обработчики снятой публичной поверхности.
Гарантия не распространяется автоматически на остальные операции
и не задаёт форму публичной квитанции.
