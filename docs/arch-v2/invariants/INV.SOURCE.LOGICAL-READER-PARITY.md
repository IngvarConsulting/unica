# Неперенесённые границы типизированного чтения

Каждый предусмотренный профилем типизированный читатель обслуживает свои
логические адреса. Счёт ветви равен длине достижимой коллекции, а каждый
проектор потребляет весь остаток адреса. В `props` остаются только
ограниченные локальные скаляры; неподдержанный фильтр даёт `bad_value`.

Evidence и edges кешируются только внутри actor/revision. Зарегистрированный
владелец имеет ровно одну ветвь `Module`, её счёт равен числу уникальных
допустимых ролей. Production retained authorities должны достигать всех
положительных возможностей модулей для configuration, EPF и ERF через
родительскую навигацию.

Внешние наборы доказывают каждый корневой объект строгим дескриптором,
не публикуют модули уровня конфигурации и имеют общий предел чтения
дескрипторов с поддержкой отмены. Bot использует зарегистрированную
раскладку. WebSocketClient видим в логическом дереве, но чтение его исходников
отвечает `provider_unavailable`, пока раскладка не доказана.
