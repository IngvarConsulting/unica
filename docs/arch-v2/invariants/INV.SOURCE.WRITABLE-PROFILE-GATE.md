# Формат ограничивает открытие цели и запись всей цепочки владельцев

Цель, которую порт чтения не открывает, отвечает `invalid_source`
с указанием формата. `unica.apply` над узлом, чья цепочка владельцев
содержит корень вне записываемого профиля, отказывает `invalid_source`
до первого байта.
