# Resolve подтверждает точный предмет и его расположение

`resolve` отвечает одним существующим предметом либо `not_found`.
Ранжированных кандидатов, признака близости и причины совпадения нет.
Диапазон строк соответствует строчному источнику; древовидный источник
называется `notLineBased`.

Ни один другой предметный инструмент не публикует `path` на входе и не несёт
физического пути в ответе.
