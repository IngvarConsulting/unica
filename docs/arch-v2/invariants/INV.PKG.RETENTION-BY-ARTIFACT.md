# Очистка кеша удерживает две версии каждого артефакта

Очистка оставляет две последние готовые версии каждого артефакта по времени
маркера `.ready.json`, остальные удаляет. Ссылки от версий ядра не учитываются.
Блокировки и незавершённые транзакции не считаются артефактами и не удаляются.

Неудачное удаление, в том числе занятого бинарного файла на Windows,
не прерывает установку или запуск. Неудалённая версия остаётся до следующей
очистки.

Прежнее обязательство также требовало продолжения работы старой сессии:
если её движок удалён после установки новых версий, он загружается повторно
без отказа операции. Продолжение старой сессии после очистки не подтверждено
проверкой.
