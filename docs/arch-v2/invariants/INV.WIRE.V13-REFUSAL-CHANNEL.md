# Отсутствующий аргумент называет закрытый набор значений

Форма отказа и конфликт ревизий перенесены в
[действующее правило](../../../arch/rules/mcp/refusal-channel.md).
Остаётся обязательство: отказ по отсутствующему обязательному аргументу
с закрытым доменом значений перечисляет этот домен. Матрица существующего
теста не проверяет этот случай.
