# Неперенесённые ограничения свидетельства выбора исходников

In-place bytes existence-only marker не образуют ложную семантическую
зависимость. Actor probe без terminal observation закрывает admission.

Apply переносит невызываемое и несериализуемое evidence всех входов карты.
Exact repeat сравнивается с canonical bytes без второго полного буфера.
Regular handle закрывается после capture, первый snapshot не держит handles.
Сравнение проходит по заимствованному evidence без клонирования bytes.
Отдельного durable source-selection recipe нет.
