# Каждый из восьми предметных инструментов имеет честный полезный режим

Демон исполняет хотя бы один полезный замкнутый режим каждого из восьми
инструментов. Известный нереализованный вариант отвечает `unsupported_*`,
а не изображает отсутствие провайдера. Режим чтения файлов рабочего пространства
требует выданного актором доступа, запрета следования по символическим
ссылкам и соблюдения отмены.

Проверка `production_daemon_configuration_executes_useful_modes_for_all_eight_v13_tools`
исполняет отдельные сценарии, но для `run` читает
только словарь, а справку получает от управляемого пустого поставщика.
Это не доказывает содержательное выполнение всех восьми инструментов.
