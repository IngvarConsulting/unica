# Причина отказа определяется там, где остановился допуск

Служба допуска различает причину в точке отказа и передаёт её типом;
server выбирает публичный код и сообщение. Повторный обход для
восстановления причины снаружи не допускается: он может увидеть уже
другое дерево.

Истечение срока допуска различается по результату контрольной точки,
а не выводится из отсутствия допущенного набора. Новый вид отказа
должен получить собственную причину вместо общего недопуска.
