# Форма регистрации команды платформой

Команда регистрируется полным инлайн-определением
`<Command uuid="…"><Properties><Name>…`.

Текущий читатель принимает также текстовую регистрацию `<Command>Имя</Command>`;
оба варианта присутствуют в `object_commands_are_registered_inline_without_descriptor_files`.
Обязательность полной формы для чтения этим не подтверждена.
