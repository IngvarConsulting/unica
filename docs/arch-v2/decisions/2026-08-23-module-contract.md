# Неперенесённые свойства чтения и изменения модуля

BSL-факты читатели получают из общего разборщика.

Список методов возвращает сигнатуру, документацию, привязки и эффективные
контексты без тела; флаги модуля, директива метода и препроцессор не смешиваются.
Контекстный срез тела требует явного фильтра.

Метод расширения сохраняет аннотацию и ссылку на метод расширяемого набора.
События имеют состояния `available`, `implemented`, `missing`, `invalid`;
реализующий метод ссылается на события формы, элемента, таблицы, колонки
или команды через `handles`.

`event.implement` создаёт физический модуль при необходимости
и материализует совместимые метод и привязку одной транзакцией.
