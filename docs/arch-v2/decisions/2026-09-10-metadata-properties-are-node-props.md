# Ограничения свойств узла метаданных

Структурное значение свойства представляется компактной строкой
в границе `MAX_COMPACT_PROP_BYTES`. Значение, которое не помещается
в эту границу, в `props` не включается.

`Synonym` из списка свойств пропускается: узел уже назвал его заголовком
и собственным полем `synonym`.
