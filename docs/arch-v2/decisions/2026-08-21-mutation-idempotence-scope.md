# Идемпотентность записи доказывается отдельно для каждого семейства

Универсальная гарантия повторного эквивалентного постобраза для всех
изменяющих операций снята как неподтверждённая. Для закрытого набора
обработчиков повтор доказан собственным сценарием и не заменяет файл;
это не создаёт универсальной гарантии пустых `changes`, diff, диапазонов,
событий и состояния кеша. Семантические noop-квитанции доказываются
собственными тестами соответствующих семейств.
