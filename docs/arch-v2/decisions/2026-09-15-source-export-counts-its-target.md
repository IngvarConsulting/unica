# Выгрузка сохраняет режим, расширение и связь ревизии с планом

`source.export` принимает только `mode` (`full` или `incremental`),
`sourceSet` и `extension`. Без `sourceSet` раннер берёт набор конфигурации;
для набора расширения его имя требуется и сверяется с набором. Частичная
выгрузка по объектам не входит в словарь. Preview сверяет режим и расширение
с аргументами.

Ревизия связывает проектный файл, состав наборов, аргументы, версию раннера
и цель. Квитанция считает обычные файлы без следования по ссылкам.
