# Остальные причины отказа прогрева сохраняют свой код

При отказе любого артефакта `unica-bootstrap prefetch` завершает команду
с кодом причины. Успех и ошибка диска перенесены в действующие правила.
Остальные причины, включая сетевой отказ, тайм-аут и несовпадение
контрольной суммы, ещё не проверены через CLI.
