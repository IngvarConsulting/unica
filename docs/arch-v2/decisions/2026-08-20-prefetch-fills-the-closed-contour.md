# Команда прогрева сообщает отказ кодом выхода

`unica-bootstrap prefetch --plugin-root <путь>` после успешного прогрева
выходит с кодом 0. Отказ любого артефакта завершает команду с кодом причины.

Манифест дерева разработки с `development: true` не содержит публикуемых
артефактов. Команда отказывает ему как ошибке конфигурации.
