# Продолжающаяся загрузка не ограничена общим сроком

Загрузка артефакта не имеет общего срока и не расходует бюджет запуска
MCP-клиента. `timeout_connect` ограничивает установку соединения,
`timeout_read` — ожидание следующих байтов. Пока байты приходят до истечения
этого срока, загрузка продолжается.

Такая доставка может удерживать блокировку артефакта неограниченно.
Отмена ожидающего вызова её не останавливает; завершение процесса
MCP-сервера останавливает доставку. Проверка рукопожатия установленного
движка имеет отдельный срок.
