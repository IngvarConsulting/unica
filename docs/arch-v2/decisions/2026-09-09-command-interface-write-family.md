# Остаток адресации и изоляции операций интерфейса

Остаётся контракт пяти операций: `commandVisibility.set`,
`commandPlacement.set`, `commandOrder.set` и `groupOrder.set` адресуются
к `…Subsystem.<Имя>.Interface`, а `subsystemOrder.set` — к корню
конфигурации. Маршрута `main:Interface` нет. Команда указывается в
аргументах операции, адрес указывает её интерфейс.

Каждая операция меняет ровно свою секцию, сохраняя остальные данные.
Порядок задаётся полной непустой последовательностью; неполный список
не должен молча заменять прежний порядок. Проверка правки общей видимости
не доказывает весь этот контракт.
