# Выбор поставщика и политики запуска принадлежит раннеру

Выбор platform provider, таймаут, fallback и terminal receipt принадлежат
раннеру, а не модели и не аргументам публичного MCP. Проверки отдельных
адаптеров пока не доказывают эту политику для всех runtime-операций.
