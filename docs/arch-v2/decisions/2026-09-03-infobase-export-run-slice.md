# Остаток привязки preview выгрузки к окружению

Ревизия связывает точные аргументы, основной и локальный конфиги,
существующее назначение, версию раннера и выбранный им план. Apply
после изменения любого из этих входов не должен использовать прежнее
подтверждение. Проверка с заведомо чужой строкой `ifRev` не доказывает
каждую связь отдельно.
