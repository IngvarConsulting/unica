# Оставшиеся гарантии передачи результата между хранилищами

Если места для связи с TaskStore не хватает до начала операции,
квитанция завершается с `task_capacity`. После начала она сохраняет
фактический результат или `outcome_uncertain`. Уже выбранный результат
или отмена не теряются. В этих случаях TaskStore не создаёт запись
и существующие задания не вытесняются.

Пока конечный результат принадлежит квитанции, он хранится весь TTL задания.
При передаче подготовленного результата его содержимое удаляется из квитанции
только после точного чтения конечной записи TaskStore. При обычной передаче
достаточно подтверждённой незавершённой записи. Разные стадии связи с заданием
представлены одной ограниченной записью жизненного цикла, а не дублирующими
активными квитанциями.

При очистке после подтверждённого удаления TaskStore удаляются связь
и оба индекса квитанции. До точного подтверждения неопределённого удаления
эти записи сохраняются.
