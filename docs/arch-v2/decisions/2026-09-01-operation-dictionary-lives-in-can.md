# Схема apply не дублирует словарь can

Публикация словаря перенесена в
[действующее правило](../../../arch/rules/mcp/operation-dictionary.md).
Остаётся ограничение схемы `apply`: `op` — строка без перечисления имён
или объединения ветвей операций. Полный словарь публикуется через `can`,
а не дублируется в схеме. Проверки проекций `can` не доказывают форму
схемы и отсутствие второго полного каталога.
