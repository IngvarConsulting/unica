# Каждый новый вызов frontend получает новые идентификаторы

Каждый новый канонический вызов MCP получает свежие `invocationId`
и `reservedTaskId`, даже при тех же инструменте и аргументах.
Восстановление потерянного ответа использует исходные идентификаторы.
