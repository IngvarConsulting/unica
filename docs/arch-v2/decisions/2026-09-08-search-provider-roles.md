# Роль выбирает исполнителя поиска

Для `search` по своду `text` роль выбирает провайдера: `lexical` — буквальное
совпадение, `symbol` — символьный индекс, `semantic` — смысловая близость.
Без роли поиск выполняет сама Unica. Свод `names` роли не принимает.
Провайдер, не завершивший работу, возвращает отказ, а не пустой результат.

Логический `scope` переводится в контекст порта в одном месте. Порты живут
со службой и разделяют стол доставки бинарных файлов между вызовами.
Срок поиска с ролью берётся из операционной настройки пользователя;
нечитаемая настройка вызывает отказ, а не подменяется умолчанием.
