# Проектный файл создаётся по содержимому setup

`v8project.yaml` создаётся и правится человеком в редакторе или моделью
её файловыми средствами. Инструмента записи проектного файла нет.

Без проектного файла `unica.view {}` отвечает `config.state: "autodetected"`,
перечисляет найденные наборы и несёт в `setup` рекомендуемое содержимое
файла. Ответ не предлагает вызов создания файла; следующий вопрос —
`unica.check {}`.
