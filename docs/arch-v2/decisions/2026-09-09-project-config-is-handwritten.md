# Словарь Unica не содержит операции записи проектного файла

`v8project.yaml` создаётся файловыми средствами вызывающего. В Unica
нет инструмента его создания или изменения. Проверки снятого имени
`workspace.initialize` не исключают появления такой записи под другим именем.
