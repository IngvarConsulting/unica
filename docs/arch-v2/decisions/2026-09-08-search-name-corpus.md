# Поиск имён и текста сохраняет разные свидетельства совпадения

Свод `text` ищет в тексте модулей BSL, `names` — в именах и синонимах
метаданных. Попадание по имени несёт `at`, `kind`, `title`, попадание
в тексте — `scope`, `line`, `column`, `snippet`. Физического пути нет
ни у одного свода. Аргумент `kind` сужает поиск по именам до одного вида
узла. Совпадение по близости названо полем `approximate`.

Текст читается на аренде ревизии и отдаёт `rev`. Справочник имён ревизией
не является и просит раскладку; он также обслуживает `resolve`.
