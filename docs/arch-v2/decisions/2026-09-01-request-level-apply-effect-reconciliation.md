# Ошибка сохраняет номер операции в исходном запросе

`apply` сохраняет исходный индекс `ops[i]`, когда передаёт операции разным
планировщикам. Ошибка на границе семейств операций указывает этот индекс,
а не номер операции внутри отдельной группы.
