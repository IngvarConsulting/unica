# Правило заявляет ровно то, что проверяет

**Решение.** Утверждение, которому нет проверки, из инварианта убирается, а не
остаётся рядом с проверяемыми. Если оно важно, оно возвращается отдельным
правилом вместе со своей проверкой.

**Почему.** Реестр обещает, что инвариант проверяем. Составное правило, где
проверена одна часть из трёх, это обещание нарушает молчаливо: страж зелен,
адрес назван, а две трети утверждения не держит ничто. Читатель при этом
опирается на всё правило целиком.

**Замер 19.08.** Разбор сорока шести правил: тридцать называли файл вместо
теста, и у части из них причина была не в адресе — правило говорило больше, чем
проверяло. `INV.APP.HIDDEN-SERVICES` заявлял невидимость служебных процессов,
ленивый запуск и границы рабочего пространства; проверка нашлась только на
границы.

**Цена.** Реестр перестаёт хранить намерения. Убранное утверждение исчезает из
письменного следа, и вернуть его придётся заново — уже с проверкой.
