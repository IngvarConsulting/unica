# Некорректная форма задания имеет собственный отказ проекции

Несогласованная комбинация status/result/failure должна возвращать
`task_projection_failed` в get и result до публикации содержимого.
В текущем V5 некорректный wire snapshot отвергается строгим декодером
и до адаптера не доходит; отдельная проверка адаптера подставляет только
типизированные снимки. Перенос этого кода на реальный маршрут не доказан.

После разбора ответа проверяется исходный cutoff с привязкой к тому же
monotonic clock. Истечение срока имеет приоритет над поздним valid или
malformed payload. Проверки задержанного сетевого ответа не изолируют
истечение срока именно во время разбора.
