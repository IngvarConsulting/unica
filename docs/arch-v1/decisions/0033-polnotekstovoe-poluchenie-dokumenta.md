# ADR-0033: Полнотекстовое получение документа по локатору попадания

- Статус: `accepted`
- Дата: `2026-08-09`
- Задача: https://github.com/IngvarConsulting/unica/issues/242

## Контекст

ADR-0029 п.4 объявляет доказательством поведения платформы текст открытой
страницы и прямо говорит, что заголовок и фрагмент поисковой выдачи
доказательством не являются. При этом ни ADR-0029, ни ADR-0032 полнотекстового
получения не вводили — обе записи откладывали его за этап 3 задачи #242, и до
этой записи публичная поверхность отдавала только фрагмент: доказательная
планка была объявлена, но недостижима маршрутом MCP.

Каждое попадание `unica.documentation.search` уже несёт устойчивый локатор
`documentId` (ADR-0029 п.8). Эта запись делает локатор ключом получения.

## Решение

1. Публичная поверхность прирастает инструментом `unica.documentation.get`:
   полный текст одного документа по `documentId` попадания, переданному
   дословно. Обязателен только `documentId`; `language` и `platformVersion`
   действуют так же, как у поиска.
2. Владелец локатора — поставщик, который его выпустил. Форматы локаторов
   поставщиков не пересекаются: `platform-syntax-help:<корпус>:<путь>` у
   установки, абсолютный адрес страницы площадки у `kb-1ci`, адрес
   `https://v8std.ru/...` у сервера стандартов. Владельца находит первый
   не-пустой ответ в порядке реестра; локатор без владельца — отказ,
   называющий сам локатор.
3. Ответ — типизированный документ с тем же происхождением, что у секции:
   поставщик, корпус, смысл источника, авторитетность, локаль, которой
   документ ответил на самом деле, применимая версия и полный текст. Отказ
   владельца — отказ вызова: подмена другой страницей или другим поставщиком
   запрещена.
4. Правила поставщиков действуют и здесь. Политика `unica.toml` с машинным
   оверлеем `unica.local.toml` отвечает отказом до единого обращения к сети;
   граница объявленных корней `kb-1ci`
   действует и на получение — адрес вне категорий руководств не
   запрашивается; адрес без версии руководства отвечается отказом, а не
   догадкой. Отмена вызова проверяется до сетевого обращения.
5. Установка читает ЗАПИСЬ страницы из контейнера точечно — по имени записи
   архива внутри `FileStorage`, вместе с соседней `<stem>.st` ради сигнатуры, —
   а не разбирает корпус целиком и не удерживает полный текст в поисковом
   индексе: инфлейт всех страниц ради одной стоил секунды на вызов, а битый
   поток соседней записи валил весь контейнер. `kb-1ci` строит адрес
   серверного рендера прямо из локатора и не обходит дерево. `v8std`
   пользуется тем же движком, что и фасад `unica.standards.explain`
   (`v8std_get_page`).

## Неграницы

1. Решение не добавляет поставщиков и не меняет контракт
   `unica.documentation.search`.
2. Решение не вводит пакетного получения нескольких документов за вызов.
3. Требующие аутентификации источники остаются неграницей, как в ADR-0032.

## Последствия

1. Доказательная планка ADR-0029 п.4 становится достижимой маршрутом MCP:
   скилл подтверждает ответ текстом открытой страницы, а не фрагментом.
2. Локатор `documentId` становится публичным ключом: его формат — часть
   контракта поставщика, и переименование поставщика или перекладка корпусов
   меняет локаторы осознанно, записью решения.

## Верификация

- `cargo test -p unica-coder the_first_provider_owning` и соседние тесты
  `application::documentation` — диспетчеризация по владельцу, отказ без
  владельца с локатором в тексте, отказ владельца как отказ вызова, отказ на
  пустом `documentId`.
- `cargo test -p unica-coder the_documentation_get` — ветка диспетчера:
  аргументы доходят до владельца, документ возвращается типизированным
  `data.document`, сухой прогон отвечает предпросмотром и требует
  `documentId`.
- `cargo test -p unica-coder get_returns_the_full_page` — установка: полный
  текст длиннее фрагмента, подстановка локали названа, чужой локатор — не
  мой, пропавшая страница — отказ с её именем.
- `cargo test -p unica-coder kb_get` — `kb-1ci`: страница по локатору без
  обхода дерева, граница объявленных корней, версия из адреса, запрет
  политики без обращения к сети.
- `cargo test -p unica-coder v8std_get` — `v8std`: тело стандарта по адресу,
  «не найден» и запрет политики как отказы владельца.
- `python3.12 scripts/ci/generate-tool-surface.py --check` — синхронность
  ведомости с новым инструментом.
