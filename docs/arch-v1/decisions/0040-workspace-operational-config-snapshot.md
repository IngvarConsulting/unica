# Остаток: жизненный цикл операционных настроек

На вызов, использующий операционные настройки, создаётся один новый снимок.
Файлы не перечитываются посреди вызова; ошибка загрузки обнаруживается
до запуска поставщика. Отмена имеет приоритет перед одновременно полученной
ошибкой конфигурации.

`tools/list` остаётся статическим: не читает настройки рабочего пространства
и не раскрывает их эффективные значения в схемах и аргументах. Эффективные
значения не добавляются и в результаты предметных инструментов.

Загрузчик, слои, диапазоны и передача бюджета перенесены в действующие правила.
Остаётся проверить эти границы на каноническом пути демона: старые тесты
вызовов `unica.code.*` сами по себе его не подтверждают.
