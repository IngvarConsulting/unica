# Компактный русский обзор screening по issue #186

- Date: `2026-08-04`
- Status: `approved`
- Decision: `none` — no architectural contract changed

## Контекст

Полный source-backed screening по issue #186 опубликован на английском языке в
`docs/provenance/reviews/2026-08-03-issue-186-source-screening.md`. Он содержит
SHA-срезы, лицензии, ссылки на конкретные файлы, сопоставление с Unica и
результаты обязательной перекрёстной проверки сильной моделью.

Для русскоязычного обсуждения нужен более компактный самостоятельный обзор без
дублирования всего доказательного корпуса.

## Решение

Добавить отдельный документ
`docs/provenance/reviews/2026-08-03-issue-186-source-screening-ru.md` со следующей
структурой:

1. краткая методика и граница достоверности;
2. таблица всех 19 источников: доказанный механизм, применимость к Unica и
   итоговое решение;
3. расширенные выводы по кандидатам `deep-dive`;
4. пять тематических направлений и порядок следующих исследований;
5. ссылка на английский screening как на полный evidence ledger.

Русская версия не повторяет SHA и все точечные ссылки каждой карточки. Она не
становится независимым источником доказательств: при расхождении действует
английский evidence ledger. Решения, число источников и состав shortlist должны
совпадать между документами.

## Проверка

- в таблице присутствуют ровно 19 исходных репозиториев;
- решения по каждому источнику совпадают с английским документом;
- перечислены все пять тематических направлений;
- каждый `deep-dive` раскрыт в отдельном разделе;
- относительная ссылка на полный screening разрешима;
- `tests/ci/test_design_documents.py` и `git diff --check` проходят.

## Влияние на архитектуру

Изменение добавляет только производный исследовательский документ и не меняет
публичные инструменты, пакетные контракты, runtime, границы слоёв или
архитектурные правила Unica.
