# Третья партия снятия v0.12: читатели

## Что проверялось до удаления

Из диффа собран инвентарь всех функций, удалённых вместе с читателями, и
разложен по снятым именам. Две трети — тесты формы самого реестра v0.12:
таблицы аргументов, алиасы путей, `tools/list`, карта движков. Их предмет
исчезает вместе с реестром.

Остальное — семь классов поведения. Каждый проверен зондом по проводу, а не
рассуждением:

| Класс | Ответ канонической поверхности |
|---|---|
| Совет о выгрузке 2.19 | `check` отдаёт `formatMigrationAvailable` дословно |
| Поддержка при чтении | `view` кладёт `support` в `props` |
| Проекция подсистемы | `view` на узле `Subsystem` с ветвью интерфейса |
| Страницы и курсор | `view` с `limit`/`cursor`, чужой курсор отказывается |
| Подсказки адресов | `find` с ограничением страницы |
| Документация | `docs` отказывает пустому запросу и чужому источнику |
| Наборы исходников | `view {}` называет неоднозначность, не падая |

## Что осталось на месте

Проекция узла `Template` отдаёт адрес и заголовок и не отдаёт содержимого
табличного документа, поэтому `mxl.info` и `mxl.decompile` остаются. Набор
`meta.info` — единственное доказательство движка типизированного чтения,
который зовёт канонический `view`; его перенос на движок напрямую делается
отдельно.

## Ограничения

`view` отказывает чужому курсору кодом `invalid_cursor`, которого нет в
закрытом наборе отказов поверхности. Это заморожено сценарием S299 как
задокументированный пробел и правится отдельно.
