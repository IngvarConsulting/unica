# Атомарный пакет замен BSL в одном модуле

## Задача

Разрешить одной операцией заменить несколько точных мест одного BSL-модуля,
проверив ожидаемую кратность каждого селектора и не оставляя частичного
результата при ошибке.

## Выбранный контракт

Прежняя плоская замена остаётся совместимой. Альтернативная ветвь
`replacements` содержит от 1 до 50 элементов `{selector, content,
expectedCount}` и не смешивается с верхнеуровневыми `selector`, `content` или
`position`. Все совпадения сначала разрешаются на неизменном снимке; только
после проверки кратности и отсутствия пересечений строится единый постобраз.

## Рассмотренные варианты

- Последовательные вызовы отвергнуты: между ними виден промежуточный модуль и
  последующий отказ оставляет половину связного изменения.
- Неявная замена всех совпадений отвергнута: она не доказывает ожидания автора и
  делает рост числа совпадений незаметным.
- Регулярные выражения отвергнуты: они расширяют язык селекторов и риск
  непреднамеренного совпадения без необходимости для этой задачи.

## Гарантии

Один исходный снимок, один проверенный постобраз и одна публикация сохраняют
существующую транзакционную границу. Ошибка кратности и пересечение сообщают
индексы элементов и диапазоны до записи. Preview возвращает тот же постобраз,
который применит apply.
