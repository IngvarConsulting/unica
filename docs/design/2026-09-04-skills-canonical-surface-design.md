# Скиллы после снятия читателей v0.12

## Что было проверено зондом

Прежде чем писать прозу, канонический ответ снят по проводу для каждого
предмета, который держали снятые читатели:

| Предмет | Канонический адрес и ответ |
|---|---|
| Форма | `<набор>:<объект>.Form.<Форма>` → `props`, ветви `Item`, `Attribute`, `Event`, `Module` |
| Роль | `<набор>:Role.<Роль>` → `props` со счётчиками, ветвь `Right` |
| Схема компоновки | `...Template.<Макет>` → `DataSet` → набор → `Field`, `Query`; варианты — `Setting` |
| Подсистема | `<набор>:Subsystem.<Имя>` → ветвь `Interface` → `Command` |
| Пакет XDTO | `<набор>:XDTOPackage.<Пакет>` → `Namespace`, `Type`, `Property` |
| Модуль | `...Module.<Роль>` → `Method`, `Region`, `Event`, `Body` |
| Расширение | `ext:Configuration` — идентичность и состав; `check` выбирает валидатор `cfe` |
| Документация | `unica.docs` c `source` из закрытого списка, ответ секциями |

Проверены и границы: адрес без префикса набора отклоняется `bad_value`,
недопущенный набор — `provider_unavailable`, незарегистрированный объект и
пустая ветвь — `not_found`, чужой курсор — `invalid_cursor`. `filter` — объект
и осмыслен только на проекциях модуля (`context`, `public`).

Зонд поймал две ошибки прозы до публикации: варианты настроек схемы
адресуются `Setting`, а не `Variant` (вида `Variant` в грамматике нет), и
`unica.search` принимает `scope` адресом набора-расширения.

## Чего канонический путь не отвечает

Автоматической сверки «перенесена ли вставка `&ИзменениеИКонтроль` из
расширения в конфигурацию» на поверхности нет: снятый `cfe.diff` считал её
сам. Скилл `cfe-diff` называет этот пробел и учит ручной сверке двумя
поисками вместо того, чтобы обещать несуществующий ответ.

## Контракт скиллов

`tests/ci/test_unica_skills.py` был написан по форме v0.12: карта
«скилл → его инструмент», таблицы обязательных аргументов, мост селекторов
ADR-0049. Из карт ушли снятые имена; мост остался только у читателей
табличного макета, у которых путь ещё принимается. Проверки, чей предмет —
проза снятого скилла, перенесены на уцелевший предмет: доказательства формы
ответа подсистемы остались на движке и спецификации, а не на удалённом
`SKILL.md`.
