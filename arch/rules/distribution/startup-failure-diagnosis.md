# Обработанный отказ запуска объясняет, что исправить

Если загрузчик обнаружил отказ запуска, stderr сообщает причину,
затронутый адрес или путь и способ исправления. Код выхода различает
класс причины, чтобы хост мог обработать отказ без разбора текста.

Проверен запуск без манифеста: код 78, имя отсутствующего файла и совет
исправить установку. Остальные причины ещё требуют проверки на запуске
CLI. Аварийное завершение без обработанного отказа описывают правила
записи стадий и сохранения сообщения о предыдущем запуске.
