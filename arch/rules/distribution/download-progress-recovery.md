# Зависшая загрузка возобновляется с ограниченным числом попыток

Исправная медленная загрузка не обрывается только из-за общей длительности.
Зависание или длительный практически нулевой прогресс определяются по
наблюдению за передачей. Полученная пригодная часть сохраняется, после паузы
доставка пытается продолжить загрузку по
[правилу докачки](resumable-runtime-download.md).

Число автоматических повторов одной общей доставки ограничено. Новый
ожидающий вызов не сбрасывает этот предел. После исчерпания попыток доставка
сообщает причину отказа и сохранённый объём; новое явное обращение может
возобновить загрузку. Повреждённая копия обрабатывается по правилу докачки.

Пороги прогресса и паузы подбираются на сетевых сценариях; это правило
не задаёт конкретных чисел. [Отмена ожидающего вызова](shared-engine-delivery.md)
и [срок запуска MCP](cold-start-budget.md) остаются отдельными гарантиями.
