# Повторный сбой запуска не теряет сообщение о предыдущем прерывании

После аварийного завершения запуска Unica сохраняет диагностику до
успешного завершения инициализации MCP, в которой сообщение передано клиенту.
Если следующий запуск тоже оборвался до этого момента, сообщение остаётся
доступным для следующей попытки. Повтор после неудачного запуска допустим.

После успешной инициализации уже переданное сообщение больше не повторяется.
Подтверждение прочтения сообщения ИИ не требуется. Подготовка текста или
запуск процесса сами по себе не означают, что инициализация завершена.

Сбор сведений о запуске, включая старт уже установленного ядра, описан
в [правиле записи стадий](startup-stage-record.md).
