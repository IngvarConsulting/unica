# Команда прогрева сохраняет причину отказа в коде выхода

Успешный `unica-bootstrap prefetch` завершается кодом 0, в том числе
когда все артефакты уже есть в кеше. Ошибка доступа к диску при подготовке
ядра или движка завершает команду кодом 74 и диагностикой `reason: disk`.

Проверка запускает настоящий CLI с заранее прогретым кешем, затем поочерёдно
блокирует каталог недокачанных файлов ядра и движка обычным файлом.
Сетевые отказы, тайм-ауты и ошибки контрольной суммы она не проверяет.

Отказ любого артефакта завершает весь прогрев с кодом его причины:
недоступность сети — 69, истечение допустимого ожидания — 75, несовпадение
контрольной суммы — 76. Эти сценарии ещё требуют проверки через CLI.
Ожидание сетевого ответа не задаёт общий срок исправной медленной загрузки.
