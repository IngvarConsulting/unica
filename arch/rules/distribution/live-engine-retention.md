# Очистка сохраняет движок, которым пользуется живой процесс

Установленная версия движка сохраняется, пока ею пользуется живой процесс
Unica или его работающий дочерний процесс, в том числе между вызовами движка.
Такие версии остаются сверх [обычного лимита кеша](runtime-cache-retention.md).
Очистка не должна заставлять работающую сессию повторно скачивать её движок:
без сети следующий вызов по-прежнему использует сохранённую установку.

После завершения всех потребителей версия снова доступна обычной очистке.
Аварийное завершение потребителя не должно удерживать её навсегда.
