# Символическая ссылка из исходников не переносит свою цель в пакет

Если отслеживаемый Git путь в исходниках плагина является символической
ссылкой, упаковщик прекращает копирование с ошибкой. Содержимое цели этой
ссылки не должно появиться по соответствующему пути в пакете.

Связанный тест выполняется на POSIX-системах. Он не проверяет подмену
родительского каталога ссылкой во время копирования.
