# После прерванного запуска можно узнать его последнюю стадию

До готовности MCP Unica сохраняет последнюю достигнутую стадию запуска:
что выполнялось и когда началось. Это относится и к запуску уже установленного
ядра. Запись переживает принудительное завершение процесса и доступна
следующему запуску. Она сообщает последнюю записанную стадию, но не доказывает
причину остановки.

Достаточно значимых стадий запуска; журнал каждого внутреннего шага не нужен.
Успешная инициализация MCP завершает учёт этой попытки. Записи параллельных
запусков независимы; незакрытая запись ещё работающего процесса не означает сбой.

Сообщение передаётся по [правилу сохранения диагностики](startup-notice-retention.md).
