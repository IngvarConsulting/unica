# Вызов, который уничтожает данные, исполняется с согласия человека

Исполняемые `push` с `force:true`, `infobase.restore` с `mode: replace`,
удаление установленного расширения, а также `pull` с `force:true` над набором
с несохранёнными правками или не под git исполняются только с согласия
человека. Unica спрашивает его по [правилу вопроса](../mcp/human-choice.md)
до допуска вызова и до запуска раннера: вызов, ставший фоновой задачей,
спросить уже не может.

Без согласия вызов отменяется отказом `cancelled`, база и исходники не
меняются. Клиент, который спрашивать не умеет, исполняет вызов как прежде.
Согласие относится только к тому вызову, о котором спрашивали: другой набор,
файл или аргумент требует нового вопроса. Выбор варианта другого вопроса,
который сам перезаписывает данные, — «Перезаписать базу» при расхождении базы
и набора — засчитывается как согласие на этот вызов. Превью не спрашивает.

`push` с `force:true` спрашивает «Перезаписать базу «<имя>» исходниками
набора «<набор>»?», для нескольких наборов — «…исходниками наборов «<a>»,
«<b>»?». Вариант — «Перезаписать базу»: изменения, сделанные в базе после
последнего обмена, пропадут. Код вопроса — `infobase.push_force`.

Удаление установленного расширения — `push` с `delete` — спрашивает «Удалить
расширение «<расширение>» из базы «<имя>»?». Вариант — «Удалить расширение»:
данные расширения в базе пропадут. Код вопроса — `extension.delete`.
