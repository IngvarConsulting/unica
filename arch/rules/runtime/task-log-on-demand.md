# Журнал задания читается отдельно от короткого итога

Итог задания остаётся коротким. Для разбора проблемы вызывающий отдельно
запрашивает ограниченный хвост журнала этого задания; распознаваемые секреты
скрываются по [правилу очистки вывода](stream-secret-redaction.md).
Полный журнал автоматически в итог не включается.

Публичный способ чтения и его проверка ещё не реализованы, разрыв указан
в `gap`. Проверки старого сервиса заданий не подтверждают этот маршрут.
