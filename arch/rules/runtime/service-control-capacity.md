# Занятые рабочие обработчики не блокируют управление сервисом

Когда все рабочие обработчики внутреннего сервиса заняты, новая работа
получает отказ о перегрузке. Проверка доступности, отмена и остановка сервиса
остаются доступны по отдельному управляющему пути. То же относится
к соединениям, которые заняли общие обработчики незавершёнными заголовками.

Сервис ограничен 64 общими, 8 рабочими и 8 управляющими обработчиками.
При насыщении общих обработчиков классификатор удерживает не больше
64 соединений, читает не больше 64 КиБ на соединение и отводит каждому
500 мс с момента принятия. Новое соединение вытесняет старейшее ожидающее,
если места нет. Нераспознанное переполнение закрывается.

Проверка обменивается настоящими TCP-сообщениями с сервисом; выполнение
предметной работы заменено управляемым исполнителем.
Точные границы классификатора и вытеснение требуют дополнительных проверок.
