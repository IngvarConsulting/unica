# Сбой реестра рабочих пространств останавливает приём работы

При отказе `workspace_registry_failed` во время допуска вызова демон
перестаёт принимать работу и запрашивает перезапуск. Неисправный реестр
не используется для допуска следующих вызовов.

Нехватка свободных мест и отказ в допуске некорректного рабочего пространства
сами по себе не останавливают демон. Проверка задаёт эти причины на границе
допуска; она не доказывает распознавание всех возможных повреждений реестра.
