# Платформу и способ исполнения выбирает раннер

Unica передаёт раннеру предметную операцию. Раннер выбирает подходящий
платформенный исполнитель, управляет сроком платформенного запуска и
возвращает квитанцию результата. Выбор исполнителя не становится скрытым
аргументом публичного MCP или обязанностью модели.

Перейти к другому исполнителю можно только до первого внешнего изменения.
После изменения базы или файлов повтор через другой исполнитель не должен
маскировать частично выполненную операцию.

Доступность платформы определяется для запрошенной операции. Один тонкий
клиент не даёт возможности создавать базу, загружать CF/DT или выгружать
исходники. Отказ называет недостающую возможность, а не объявляет любую
установку пригодной для любой операции.

Общий срок и отмена вызова Unica сохраняются. Проверки отдельных адаптеров
пока не доказывают эту политику для всех операций словаря.
