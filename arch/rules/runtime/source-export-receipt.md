# Выгрузка исходников подтверждает согласованную цель

`pull` выгружает один набор исходников раннером. Аргументы — `force`,
необязательные `sourceSet` и `extension`. Без `sourceSet` выбирается набор
конфигурации; для набора расширения требуется совпадающее имя расширения.
Без `force` режим выбирает раннер по своей памяти о прошлом обмене этой рабочей
копии: частичный или полный. `force:true` требует полной выгрузки и
подтверждает замену всего набора, включая незафиксированные и неотслеживаемые
файлы.

Preview `pull` принимает только объявленный набор и цель внутри рабочего
пространства, показывает относительный путь и не допускает ответа о выполненной
записи. Используется [режим previewApply](../mcp/run-operation-names.md). Ответ
раннера о другом наборе или другой цели не признаётся успехом. Запрошенный
режим и имя расширения в ответе должны совпасть с аргументами вызова. Ответ
передаёт фактический режим как `performedMode` с причиной расхождения
`modeReason`; preview называет режим плана раннера `plannedMode`.

Перед полной выгрузкой (`force:true`) Unica считает по git несохранённые правки
в каталоге набора: изменённые, удалённые и неотслеживаемые файлы, кроме
исключённых `.gitignore`. Preview называет их число в `localChanges.files` или
сообщает, что каталог не под git (`localChanges.underGit: false`);
отсутствующий каталог — правок нет. Ответ git, который не удаётся прочитать, —
отказ `invalid_state`, а не «правок нет». Частичная выгрузка набор не заменяет
и правки не считает. Каталог набора для подсчёта — путь набора из
`v8project.yaml`; без `sourceSet` — путь набора конфигурации. Исполнение
считает правки до допуска вызова. С правками или без git оно идёт только с
согласия человека по [правилу разрушающих вызовов](destructive-confirmation.md).

Исполнение проверяет объявленный состав наборов и цель выгрузки по текущему
проекту и вызывает раннер один раз. Цель пишет раннер. На время вызова правки
набора через Unica исключены [правилом](source-set-write-exclusion.md).

Успешная квитанция называет относительную цель и фактический режим. Unica не
сохраняет прежние исходники и не откатывает выгрузку: при отказе раннера цель
может содержать частичную выгрузку, и ответ предлагает повторить `pull` с
`force:true`. Состояние информационной базы между preview и применением не
фиксируется.
