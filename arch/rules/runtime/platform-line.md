# Платформу для запуска выбирает линия формата

Платформу для запуска, загрузки, выгрузки и сборки выбирает линия формата,
а не конкретная сборка: годится любая установка этой линии, из нескольких
берётся самая новая. Линию по формату проекта выбирает раннер в строгом
режиме, и этот режим включает Unica. Без установки нужной линии раннер
не переходит на новейшую установку другой линии, а отказывает. Unica
переводит этот отказ в `platformLineNotInstalled` и называет линию
и найденные установки других линий.

Пока у раннера нет строгого режима (разрыв), без установки нужной линии он
работает на новейшей установке и только предупреждает.
