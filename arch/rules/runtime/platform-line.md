# Платформу для запуска выбирает линия формата

Платформу для запуска, загрузки, выгрузки и сборки выбирает линия формата,
а не конкретная сборка: годится любая проверенная установка этой линии,
из нескольких берётся самая новая. Если установки этой линии на машине нет,
операция отказывает с `platformLineNotInstalled` и называет линию
и найденные установки других линий.
