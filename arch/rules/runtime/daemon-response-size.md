# Frontend самостоятельно ограничивает размер ответа демона

Ответ JSONL не превышает 8 МиБ + 64 КиБ. Предел ответа не выводится
из предела запроса: frontend проверяет его при чтении. Превышение или
оборванный ответ закрывают соединение; отправлять следующий запрос
в это соединение нельзя.

Код ограничивает чтение. Полная проверка oversized и оборванного ответа
с последующим запретом повторного использования соединения указана в `gap`.
