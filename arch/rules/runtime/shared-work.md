# Одинаковая фоновая работа выполняется один раз

В одном реестре общей фоновой работы для одного точного ключа одновременно
работает не более одного исполнителя. Подключившиеся потребители получают его общий
результат или ошибку. Разные ключи не объединяются: например, поставки
с разными SHA-256 остаются разными заданиями.

Подключение к заданию возвращает управление, не дожидаясь результата.
Уход одного потребителя не отменяет работу, нужную остальным. Если работа
принадлежит потребителям, а не процессу, уход последнего потребителя
отменяет исполнителя. Новая попытка для этого ключа начинается только после завершения предыдущей, в том числе
при одновременных подключении, отмене и завершении.
