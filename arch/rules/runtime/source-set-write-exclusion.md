# Операция раннера над набором исключает правки Unica

Пока `pull`, `push` или `make` исполняет раннер над набором исходников, правки
этого набора через Unica не применяются: они ждут окончания вызова в пределах
своего дедлайна или получают отказ. Запись сторонними программами мимо Unica
это правило не охватывает.
