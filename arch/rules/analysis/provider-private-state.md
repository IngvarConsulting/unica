# Формат индекса поставщика не становится форматом данных Unica

Unica обращается к индексу анализа кода через поддерживаемый интерфейс
поставщика. Она не читает его частные таблицы, не копирует и не объединяет
их ради получения результата или переноса состояния между рабочими деревьями.

Это не запрещает работу с собственными записями Unica о ревизии, готовности
и размещении индекса. Будущее совместное использование индекса допустимо
только с поддерживаемым контрактом поставщика для объединения и обновления;
его полезность должна быть подтверждена измерением.

Текущая проверка отсутствия строк SQLite в исходниках не доказывает эту
границу целиком. Содержательная проверка рабочего маршрута указана в `gap`.
