# Формат индекса поставщика не становится форматом данных Unica

Unica обращается к индексу анализа кода через поддерживаемый интерфейс
поставщика. Она не читает его частные таблицы, не копирует и не объединяет
их ради получения результата или переноса состояния между рабочими деревьями.

Это не запрещает работу с собственными записями Unica о ревизии, готовности
и размещении индекса. Будущее совместное использование индекса допустимо
только с поддерживаемым контрактом поставщика для объединения и обновления;
его полезность должна быть подтверждена измерением.

Проверки проходят канонический анализ, сервис рабочего пространства и
управляемый MCP-процесс поставщика с двумя закрытыми форматами индекса.
Поставщик сам читает свою неизменяемую сборку; Unica получает результаты
через его интерфейс. Снимок рабочего дерева проверяет сохранность индекса
и отсутствие копирования. Это проверка границы, а не совместимости
с конкретной версией внешнего анализатора.

На Linux дополнительное наблюдение открытий частного файла действует только
во время Search: поставщик читает заранее открытый дескриптор, а чтения
фикстуры выполняются вне окна. Намеренное чтение из потребителя, даже
с проигнорированным результатом, должно отвергаться этой проверкой.
