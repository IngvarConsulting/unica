# Ошибка чтения при поиске объясняет, на каком шаге он остановился

При сбое файлового ввода-вывода буквальный поиск указывает фазу: например,
открытие поддерева или чтение исходного файла. Одна сырая ошибка ОС без
контекста поиска не заменяет такую диагностику.

Отсутствие файлового поддерева у допущенного логического scope даёт
успешный пустой результат без диагностик. Исчезнувший при обходе элемент
сам по себе также не является сбоем чтения. Реальный отказ передаётся через
[канал diagnostics](../mcp/refusal-channel.md).
