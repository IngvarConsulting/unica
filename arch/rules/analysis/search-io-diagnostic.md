# Ошибка чтения при поиске объясняет, на каком шаге он остановился

При сбое файлового ввода-вывода буквальный поиск указывает фазу: например,
открытие поддерева или чтение исходного файла. Одна сырая ошибка ОС без
контекста поиска не заменяет такую диагностику.

Отсутствующее поддерево и исчезнувший при обходе элемент сами по себе
не являются сбоем чтения. Границу пустого результата задаёт
[канал отказов](../mcp/refusal-channel.md).
