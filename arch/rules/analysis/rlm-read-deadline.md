# Подготовка RLM и поиск определения расходуют один срок

В адаптере поиска определения проверка готовности индекса и сам запрос
делят общий срок выполнения. Время, потраченное на подготовку, вычитается
из времени для чтения; переход к чтению не запускает таймаут заново.

Тест с управляемыми часами проверяет остаток времени, переданный обеим стадиям.
