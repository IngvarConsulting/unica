# Поиск справки сохраняет порядок и происхождение ответов

Секции результата идут в порядке регистрации поставщиков, а не по алфавиту
их имён. Секция передаёт вид источника, авторитетность, корпус и фактический
язык ответа; попадание — версию, к которой относится документ.
Язык запроса не подменяет язык полученного материала.
