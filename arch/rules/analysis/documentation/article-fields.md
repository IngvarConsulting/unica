# Статья справки платформы отдаётся полями по виду статьи

Открытая страница справки платформы приходит не только текстом: `unica.docs`
отдаёт рядом с ним разобранную статью. Вид статьи — метод, свойство,
конструктор, событие, тип или понятие — задаёт, какие поля у неё бывают;
поля другого вида в ответе отсутствуют ключом, а не стоят пустыми.

Статья называет владельца и имя русским и английским, варианты синтаксиса
со строкой вызова и параметрами (имя, типы, обязательность, значение
по умолчанию, описание), возвращаемое значение с типом, тип свойства,
«только чтение», места исполнения устойчивыми значениями, версию появления,
описание, примечание и пример кодом. Место исполнения, которого справка
ещё не называла, приходит как написано, а не теряется.

Каждая ссылка статьи — на владельца, на тип параметра или возврата, на члена
типа — приходит локатором документа того же корпуса, по которому статья
открывается. Отдельного раздела связанных статей у справки платформы нет:
ссылки стоят внутри текста, и статья отдаёт их списком.

Разбор следует справке выбранной установки: чего справка не называет,
статья не выдумывает. Состояния полей задаёт
[три состояния](article-field-states.md), сведения о происхождении —
[документ владельца](document-owner.md).
