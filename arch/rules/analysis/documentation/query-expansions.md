# Дополнительные поисковые слова могут найти справку без прямого совпадения

Поисковый индекс использует переданные расширения запроса, даже когда
исходные слова не дали попаданий. Например, расширения `group`, `table`
и `value` помогают запросу «свернуть таблицу значений» найти английский
документ о таблице значений.

Правило относится к использованию готовых расширений; их автоматический
перевод этой проверкой не подтверждается.
