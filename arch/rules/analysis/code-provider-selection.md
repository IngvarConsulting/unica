# Чтение кода получает поставщик с нужной возможностью

Реестр выбирает поставщика, который поддерживает запрошенную возможность.
Поставщик без неё пропускается, даже если стоит первым. Например, граф
вызовов получает поставщик с этой возможностью, а стоящий перед ним поставщик
только текстового поиска не перехватывает вызов. Если поставщика роли нет,
запрос получает отказ с причиной, а роль остаётся в контракте.

Результат сохраняет идентичность фактически вызванного поставщика.
