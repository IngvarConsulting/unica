# Предпросмотр применения метаданных не запускает индексирование

При публичном предварительном просмотре изменений метаданных (`unica.apply`
без `executionToken`) Unica не начинает строить поисковый индекс проекта
и не изменяет файлы его состояния.

Тест наблюдает вход в запуск изолированной сборки и заранее создаёт устаревшие
состояние и блокировку, которые проверка готовности индекса восстановила бы
с записью. После предпросмотра запуск не наблюдается, а дерево состояния
остаётся байт-в-байт прежним.
