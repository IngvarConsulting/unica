# Применение правок соблюдает запрет редактирования объекта поставщика

При политике `deny` планировщик `unica.apply` отказывает с `invalid_state`,
если правка касается узла, закрытого для редактирования, или изменения
запрещены для всей конфигурации на поддержке. Узел закрыт, если запрет стоит
на его объекте верхнего уровня или на любом узле пути к нему со своей записью
поддержки: форме, макете, команде, реквизите, табличной части, её реквизите,
измерении, ресурсе, вложенной подсистеме. Модуль формы следует запрету формы,
модуль объекта — запрету объекта. При отказе исходники не меняются
и подготовленный пакет правок не возвращается.

Нечитаемое или повреждённое состояние поддержки `Ext/ParentConfigurations.bin`,
как и описание объекта без идентификатора, по которому ищется его правило,
не означает её отсутствия ([чтение поддержки](sources/support-state-read.md)):
при `deny` и `off` правка отклоняется с `invalid_source` до изменения
исходников, при `warn` проходит с предупреждением `support_locked`. Отсутствующий файл
по-прежнему означает, что конфигурация не на поддержке.

С отказом из-за нечитаемого `ParentConfigurations.bin` Unica спрашивает человека по
[правилу вопроса](../mcp/human-choice.md): «Состояние поддержки поставщика
у набора «<набор>» повреждено и не читается.», вариант «Снять с поддержки
полностью» — сведения о поставщике и правила объектов пропадут, обновления
поставщика перестанут приходить; «Отменить» — восстановите базу из резервной
копии и выгрузите набор заново; код `support.state_unreadable`. Выбор готовит
один план: вместо повреждённого состояния записывается состояние
конфигурации, полностью снятой с поддержки, как его пишет платформа, и
исходная правка публикуются вместе; исполняет его обычный `apply` по
`executionToken`.

Исключение — пакет только из операций `supportCapability.set` и
`supportRule.set`: они позволяют изменить саму защиту. Добавление такой
операции не разрешает другие правки в том же пакете. Например, модель не
может одним пакетом открыть объект и тут же изменить его свойство.

С отказом Unica спрашивает человека по [правилу вопроса](../mcp/human-choice.md).
Закрыт объект — «Объект «<объект>» набора «<набор>» на поддержке
поставщика: правка запрещена.», код `support.object_locked`; `<объект>` —
узел, на котором стоит запрет, и выбранный вариант меняет правило этого узла. Изменения
запрещены для всей конфигурации — «Конфигурация набора «<набор>» на
поддержке поставщика без возможности изменения.», код
`support.configuration_locked`. Варианты обоих вопросов: «Разрешить правку
с сохранением поддержки» — при обновлении от поставщика по объекту возможны
конфликты; «Снять объект с поддержки» — обновления поставщика по объекту
перестанут приходить; «Отменить» — доработку можно внести в расширение.
Для конфигурации выбранный вариант также включает возможность её изменения.
Выбор готовит [один план](sources/support-separate-apply.md) из изменения
поддержки и исходной правки; исполняет его обычный `apply` по
`executionToken`. Ответ человека политику проекта не меняет.
