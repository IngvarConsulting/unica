# Демон ограничивает число акторов и сохраняет недавно использованные

Демон допускает не более 64 одновременно живых `WorkspaceActor`.
Параллельные обращения к одному профилю получают один актор. Новый профиль
при занятой ёмкости получает повторяемый отказ `workspace_capacity`;
повреждение реестра даёт `workspace_registry_failed` и закрывает приём.

После завершения вызовов сохраняются не более восьми недавно использованных
акторов. Повторное использование продвигает актор в начало этого набора;
при переполнении удаляется наименее недавно использованный. Срок хранения
без обращений — 600 секунд. При обслуживании реестра просроченные акторы
освобождаются, а при подмене именованного корня следующий вызов создаёт
новый экземпляр.

При нехватке ёмкости сначала освобождаются неиспользуемые сохранённые акторы.
Актор, нужный выполняющемуся вызову, не вытесняется. Завершённые рабочие
пространства не накапливают удерживаемые каталоги сверх этого набора.
