# Каталог кеша анализатора выбирается вне исходников

Если Unica успешно рассчитала путь для кеша BSL-анализатора, этот путь должен
находиться за пределами исходников. Ключ кеша рассчитывается по приведённым
к единому виду путям проекта и исходников. При выборе другого каталога кеша
этот ключ сохраняется.

Например, если исходники занимают весь каталог проекта, путь `.build/unica`
внутри него не подходит: нужен внешний каталог. Связанный тест проверяет
выбор пути именно в этом случае.

При обновлении Unica разрешены новый адрес кеша и перестроение индекса.
Совместимость адреса между версиями не обязательна. Это разрешение не
распространяется на удаление прежнего `.build` внутри исходников: там могут
находиться файлы других инструментов или пользователя.
