# Смена ветки учитывается и в связанной рабочей копии Git

При определении эпохи проекта Unica читает HEAD из каталога Git,
на который указывает файл `.git` рабочей копии. Переключение ветки
не остаётся незамеченным из-за того, что `.git` здесь файл, а не каталог.

Эпоха — признак изменения состояния проекта для потребителей кеша.
Проверка сравнивает эпохи после переключения HEAD между ветками;
она не проверяет полную перестройку всех кешей.
