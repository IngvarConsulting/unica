# Формат набора — семейство и кортеж версий, линия платформы — его часть

Формат набора исходников задаётся семейством форматов и кортежем версий
этого семейства. У выгрузки Конфигуратора кортеж — версия формата
из атрибута `version` корневых файлов, одна на выгрузку; линия платформы
однозначно выводится из неё: 2.17 — 8.3.24, 2.18 — 8.3.25, 2.19 — 8.3.26,
2.20 — 8.3.27, 2.21 — 8.5.1, 2.22 — 8.5.4. У другого семейства линия может
быть отдельным элементом кортежа; например, у EDT кортеж — версия EDT
и `Runtime-Version` проекта. Разные кортежи — разные форматы: чтение и запись
выбирают правила формата по всему кортежу. Режим совместимости в формат
не входит.

Сравнивать и упорядочивать кортеж умеет только его семейство; версии разных
семейств не сравниваются.
