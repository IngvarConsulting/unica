# Полная выгрузка публикуется только с допустимыми XML-корнями

Перед публикацией полной выгрузки проверяются корни файлов `.xml`.
Тип документа определяется именем корневого элемента и пространством имён.
Незарегистрированный тип отклоняется независимо от наличия `version`.

Для зарегистрированных типов соблюдается их правило версии: точное
поддерживаемое значение либо отсутствие атрибута у документов без версии.
Например, СКД с атрибутом `version` не проходит эту проверку, а без него
остаётся допустимой.
