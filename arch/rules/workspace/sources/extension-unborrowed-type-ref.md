# Ссылка расширения на незаимствованный тип читается по имени

Тип объекта основной конфигурации, который не заимствован в расширение,
платформа выгружает как `<v8:TypeId>`. Его GUID равен `TypeId`
из `GeneratedType` этого объекта в основной конфигурации. Заимствованные
и собственные объекты расширения выгружаются именованными ссылками.

`pull` публикует выгрузку платформы без изменений и не заменяет `TypeId`
именем. Разрыв с исходниками до загрузки остаётся видимым в diff,
а повторный `pull` его не меняет.

Чтение исходников расширения разрешает `TypeId` в имя типа по `GeneratedType`
основного набора. GUID, которого в основном наборе нет или который найден
у нескольких типов, даёт диагностику с GUID и местом. Такая ссылка не
скрывается и не отклоняет чтение. Платформа загружает неизвестный GUID
без ошибки, поэтому битую ссылку обнаруживает только эта диагностика.
Разрешённое имя служит показу и поиску. Сохранённый `TypeId` от этого
не становится логической целью правки: для источников подписки действует
[правило их правки](event-subscription-source-local-change.md).

Правка исходников расширения, которая записывает тип незаимствованного
объекта основной конфигурации, предупреждает: после загрузки и выгрузки
он станет `TypeId`. Читаемая и стабильная альтернатива — заимствовать объект.

Публикация `pull` без изменений выполняется сейчас. Разрешение `TypeId`
при чтении, диагностика неразрешённого GUID и предупреждение при правке
ещё не реализованы; их доводит и подтверждает тестами задача из `gap`.
