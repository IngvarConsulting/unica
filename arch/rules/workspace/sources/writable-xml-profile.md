# Для редактирования нужен записываемый формат выгрузки

Записываемые форматы XML-выгрузки — те, у которых есть диалект кодеков и
эталон выгрузки: `2.20` (`8.3.27`), `2.21` (`8.5.1`) и `2.22` (`8.5.4`).
Правка сохраняет формат набора: новые файлы получают формат своих владельцев.
Правка набора, корни которого записаны в разных форматах, отклоняется с кодом
`formatVersionMixed` без изменения байтов. Нативная операция отклоняет старый
формат без изменения исходных байтов. По выбору человека Unica перевыгружает
набор в записываемом формате через временную файловую базу; сама правка формат
не меняет. С отказом `formatMigrationAvailable` Unica спрашивает человека по
[правилу вопроса](../../mcp/human-choice.md): «Набор «<набор>» выгружен в
формате <формат>. Правки доступны с формата <целевой> (платформа <линия>).»,
вариант «Перевыгрузить набор в формате <целевой>» — файлы набора перезапишутся,
несохранённые правки в них пропадут; код `source.format_old`. С отказом
`formatVersionMixed` — «Корни набора «<набор>» выгружены в разных форматах:
<ф1> и <ф2>. Правка сохраняет один формат.», по варианту на каждый формат
«Перевыгрузить в формате <ф> (<платформа>)» с той же строкой; код
`source.format_mixed`. Выбранный вариант перевыгружает набор и повторяет
правку. Перевыгрузка загружает набор во временную файловую базу платформой
линии целевого формата и выгружает его обратно в каталог набора; база проекта
и файлы проекта не меняются, временная база удаляется.

Правка требует режима совместимости не ниже 8.3.8. Набор с режимом 8.1, 8.2.x
или 8.3.1–8.3.7 доступен только для чтения: чтение, поиск, анализ и
`unica.check` работают. Единственная допустимая правка — установить набору
режим совместимости 8.3.8 или новее. Любая другая правка отклоняется с кодом
`compatibilityModeUnsupported` без изменения байтов, и отказ называет режим
набора, минимальный режим 8.3.8 и то, что режим можно повысить. С отказом
Unica спрашивает человека по [правилу вопроса](../../mcp/human-choice.md):
«Набор «<набор>» в режиме совместимости <режим> можно только читать. Правки
доступны с режима 8.3.8.», вариант «Повысить режим до 8.3.8 и внести
правку» — поведение конфигурации может измениться; код
`source.compatibility_mode`. Выбор готовит один план: установка режима 8.3.8
и исходная правка публикуются вместе, исполняет его обычный `apply` по
`executionToken`. Режим конфигурации — её `CompatibilityMode`, режим
расширения — его собственное `ConfigurationExtensionCompatibilityMode`.

Платформа не применяет расширение, режим совместимости которого выше режима
основной конфигурации. Правка, поднимающая режим расширения выше режима основы
или опускающая режим основы ниже режима её расширений, допустима, но ответ
правки и проверка предупреждают: платформа такое расширение не применит.
Предупреждение называет оба режима и основу.

Значение `version` записывается буквально как одна из записываемых версий.
Численно равные варианты (`2.20.0`, `02.20`, `2.020`) и написания через
XML-сущности, например `2.&#50;0`, недопустимы. Такой отказ не меняет исходники и не создаёт событий
или артефактов операции. Проверяется исходная запись атрибута до декодирования
XML-сущностей.

Чтение решает семейство форматов по своим известным версиям. У `platform_xml`
известны версии, для которых есть эталон выгрузки: от `2.17` до `2.22`.

- Известная версия читается. Пока у неё нет своего диалекта, каноническая
  проверка узла `unica.check` сообщает `formatVersionUnverified` с семейством,
  версией (`actual`) и версией диалекта, по которому прочитано (`readAs`).
- Неизвестная версия новее самой новой известной читается по ближайшему
  известному диалекту с той же находкой.
- Неизвестная версия старше самой старой известной или между известными,
  а также корень без `version` (формат `1.0`) не читается: отказ
  `formatVersionUnsupported` с семейством, версией и списком известных.

Запись в любую версию, кроме записываемых, отклоняется без изменения байтов:
старше `2.20` — `formatMigrationAvailable`, новее `2.22` —
`platformVersionUnsupported`.
Предварительный `apply` над такими исходниками отказывает с `invalid_source`
и указывает несовместимый формат владельца.
