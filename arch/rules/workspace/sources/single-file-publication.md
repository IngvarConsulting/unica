# Ошибка подготовки замены файла сохраняет его содержимое

При замене существующего файла обработанная ошибка до публикации сохраняет
его исходные байты и удаляет временный файл с подготовленной заменой.
Это проверяется на этапах записи, установки прав, сброса данных на диск,
валидации и повторной проверки перед заменой.

Аварийное завершение процесса находится за границей этой проверки.
