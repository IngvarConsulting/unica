# Замена кода проверяет ревизию прочитанного текста

Успешный `view` с текстом `Body` и ответ LSP
`workspace/textDocumentContent` возвращают в `rev` ревизию полного
текста модуля. Диапазон строк и тело метода несут ревизию модуля, из
которого взят фрагмент. Ревизия учитывает переводы строк и исключает
начальные метки BOM. LSP использует открытый буфер, если он есть в этом
соединении. Одинаковый текст через оба входа даёт одинаковую ревизию.

`code.replace` принимает необязательное `ifRev` в аргументах операции.
План сверяет его с исходным текстом на момент планирования вызова, до
изменений других операций того же плана. При несовпадении план возвращает
`conflict` по `ops[<i>].args.ifRev` без записи. Без `ifRev` замена
работает по прежнему контракту.

[Применение по `executionToken`](../apply-revision-fence.md) исполняет
сохранённый план. Изменение его входов по-прежнему даёт
[`stale_revision`](projected-revision-equality.md).
