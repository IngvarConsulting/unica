# Читатель СКД сохраняет настройки данных и вариантов отчёта

Модель чтения СКД содержит источники данных, имя объекта и источник набора,
группу итога, ограничения вычисляемого поля и доступность параметра как поля.
Для варианта сохраняются имя, представление, выборка, число фильтров,
сортировка и структура группировок. Состояние поддержки владельца
остаётся частью результата чтения.

Проверка относится к внутреннему читателю СКД. Она не доказывает передачу
всех этих фактов через каждую публичную проекцию `view`.
