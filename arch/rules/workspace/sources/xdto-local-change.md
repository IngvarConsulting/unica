# Изменение схемы XDTO сохраняет остальной текст пакета

Добавление и удаление типов и свойств, смена основы типа и переименование
свойства меняют только выбранный `XDTOPackages/<Имя>/Ext/Package.bin`.
Дескриптор объекта метаданных остаётся отдельным ресурсом.

Пакет изменяется локально: байты за пределами правки, начальный BOM
и переводы строк сохраняются. Смена основы меняет только атрибут `base`
выбранного типа; если префикс основы не объявлен в области типа, рядом
с атрибутом повторяется его единственное объявление из пакета. Имя, свойства,
ограничения, прочие атрибуты типа и его место остаются прежними, прежняя
основа файла не меняет. Переименование меняет только значение атрибута
`name` выбранного свойства; его тип, границы, `localName` и место среди соседей
остаются прежними. Для вставки используется перевод строки рядом с целью;
при смешанном стиле без такого образца писатель отказывает.
Проверки проходят планировщик операций и писатель пакета.
