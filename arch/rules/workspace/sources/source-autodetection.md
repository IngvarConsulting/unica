# Без описания проекта исходники ищутся только в известных каталогах

Если `v8project.yaml` отсутствует, базовая конфигурация ищется по порядку
в корне проекта, `src` и `src/cf`. Выбирается первое совпадение.
Признаком корня служит один из файлов: `Configuration.xml`,
`Configuration/Configuration.mdo` или `src/Configuration/Configuration.mdo`.

Расширения ищутся в `src/cfe` и `src/extensions`. Первый каталог может сам
быть корнем одного расширения; тогда его дочерние каталоги не считаются
другими расширениями. Иначе оба каталога содержат отдельные расширения,
распознаваемые по тем же файлам.

Имя расширения берётся из имени его каталога без изменения регистра или другой
нормализации. Каталог с именем, которое нельзя представить в UTF-8, пропускается;
остальные расширения продолжают обнаруживаться. Имя `main` получает найденная
базовая конфигурация, а при её отсутствии — первое претендующее на него
расширение. Второй набор с этим именем не добавляется. О пропущенных наборах
сообщает [диагностика конфликта](autodetected-main-conflict.md).

Файл или ссылка на месте конечного каталога расширений либо его дочернего
каталога пропускается. Если содержимое контейнера не удалось прочитать,
поиск завершается ошибкой, а не выдаёт его за пустой. Обычный и контролируемый
поиск используют один каталог раскладок и маркеров; использованный список
дочерних каталогов входит в сведения для повторной проверки карты.

Проверка имени не в UTF-8 выполняет этот сценарий только на файловой системе,
которая позволяет создать такую фикстуру.
