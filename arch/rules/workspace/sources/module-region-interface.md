# Области определяют программные интерфейсы без новых адресов методов

`Public` содержит экспортные методы области `ПрограммныйИнтерфейс`.
`Library` добавляет экспортные методы `СлужебныйПрограммныйИнтерфейс`,
а `Override` содержит методы `ПереопределяемыеПроцедурыИФункции`
независимо от экспорта. Экспорт вне этих областей не включается автоматически.
Проекция сохраняет исходные адреса методов.

Метод в `view` называет поле `area` — ближайшую нормативную область, которая
его охватывает: `public` — `ПрограммныйИнтерфейс`, `internal` —
`СлужебныйПрограммныйИнтерфейс`, `crossSubsystem` —
`ДляВызоваИзДругихПодсистем`, `override` — `ПереопределяемыеПроцедурыИФункции`,
`private` — `СлужебныеПроцедурыИФункции`, `deprecated` —
`УстаревшиеПроцедурыИФункции`. Области с другими именами между методом и
нормативной областью не учитываются. Экспорт на значение не влияет. У метода
вне нормативных областей поля нет.

Вложенная область имеет полный адрес. Одноимённые соседние области видны
как неадресуемые записи; запрос неоднозначного адреса отклоняется.
Проверка проходит построитель проекции модуля.
