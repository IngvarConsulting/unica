# Чтение учитывает права конфигурации с неизвестными именами

При чтении роли неизвестное Unica имя права на конфигурацию не вызывает
отказ и не исключает право из результата. Разрешённые и запрещённые права
учитываются в соответствующих счётчиках. Чтение не меняет исходный файл.

Это не подтверждение допустимости права для платформы и не разрешение
записывать произвольные имена. Правило относится к чтению прав конфигурации,
а не к их проверке или редактированию.
