# Структура модуля строится из его текущих исходников

Читатель модуля разбирает BSL выбранного набора исходников и сохраняет
результат только в пределах одного чтения. Изменившийся модуль требует нового
разбора; готовность поискового индекса не подменяет актуальность этого чтения.
Проверка считает разборы: одно чтение использует один разбор, после
изменения файла выполняется новый. Свежесть самого ответа и изоляция
его содержимого между акторами требуют проверки из `gap`.
