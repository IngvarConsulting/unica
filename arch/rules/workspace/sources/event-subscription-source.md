# Подписка может выбирать семейство источников события

Источник подписки можно задать семейством объектов, без перечисления
конкретных объектов метаданных. Например, `catalogObject` означает объекты
справочников и не требует наличия отдельного справочника.

Типизированная запись сохраняет этот выбор в XML, а чтение возвращает
то же семейство. Повторная установка того же источника не создаёт изменений.
