# MCP SDK знает только дверь MCP

MCP SDK и транспорт MCP знает только дверь MCP. Ядро, демон и остальные
компоненты от SDK не зависят и его типов не называют: вызов инструмента
и его результат они передают через протокол демона и контракты приложения.

Протокол MCP — рукопожатие, согласование версии, разбор и отмена
запросов — в производственной сборке двери ведёт официальный SDK, а не
собственный цикл двери.
