# Строка коллекции объектов называет синоним и число подчинённых

Строка коллекции объектов метаданных верхнего уровня, например `main:Catalog`
или `main:Document`, содержит адрес `at`, вид `kind` и имя объекта в `title`.
Для объекта с читаемым дескриптором свойства `props` включают:

- `synonym` — синоним объекта в форме [НСтр](../workspace/sources/localized-string-nstr.md);
  поле опускается, если синоним не задан;
- `children` — число записей `ChildObjects` дескриптора объекта: реквизитов,
  табличных частей, измерений, ресурсов, форм, команд, макетов и других.

`children` не равно сумме `count` ветвей узла объекта: стандартные реквизиты,
предопределённые элементы, модули и характеристики в него не входят. Число
берётся из уже разобранного при чтении коллекции дескриптора, поэтому строка
не требует полного чтения каждого объекта.

Если синоним превышает компактный предел свойства, `limits` строки
содержит адрес его полного чтения. Нечитаемый синоним оставляет строку
без `synonym`, а `limits` строки называет причину. Размер страницы
определяет [общее правило страниц чтения](read-page-budget.md).
