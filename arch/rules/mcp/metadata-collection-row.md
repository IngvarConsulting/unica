# Строка коллекции объектов называет синоним и число подчинённых

Строка коллекции объектов метаданных верхнего уровня, например `main:Catalog`
или `main:Document`, содержит адрес `at`, вид `kind`, имя объекта в `title`
и `props` с двумя полями:

- `synonym` — синоним объекта в форме [НСтр](../workspace/sources/localized-string-nstr.md);
  поле опускается, если синоним не задан;
- `children` — число записей `ChildObjects` дескриптора объекта: реквизитов,
  табличных частей, измерений, ресурсов, форм, команд, макетов и других.

`children` не равно сумме `count` ветвей узла объекта: стандартные реквизиты,
предопределённые элементы, модули и характеристики в него не входят. Число
берётся из уже разобранного при чтении коллекции дескриптора, поэтому строка
не требует полного чтения каждого объекта.

Строка не растёт вместе с объектом: в ней нет вложенных структур, а синоним
длиннее компактного предела свойства уходит в `limits` с адресом полного
чтения. Поэтому страница коллекции по умолчанию имеет ограниченный размер,
и перечисление пополняет контекст агента предсказуемыми порциями. На
конфигурации класса УТ страница по умолчанию не больше 8800 байт компактного
JSON. Это граница размера, а не точный счёт токенов.

Нечитаемый синоним не обрывает страницу: строка остаётся без `synonym`,
а её `limits` называет причину. Строки вида, раскладка дескриптора которого
не определена для линии платформы (клиент WebSocket), `props` не содержат.
