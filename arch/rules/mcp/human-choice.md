# Выбор, который принадлежит человеку, Unica задаёт вопросом

Unica спрашивает человека в ходе вызова в двух случаях: отказ, после
которого есть несколько путей и выбрать должен человек, и вызов, который
уничтожает данные. Какие это случаи и какие у них тексты, задают правила
операций.

Спрашивают только клиента, который объявил такую возможность. Сессия до
протокола 2026-07-28 получает запрос `elicitation/create` в форме внутри того
же `tools/call`. Клиент протокола 2026-07-28 получает `InputRequiredResult` и
повторяет вызов с ответом; состояние повтора привязано к вопросу, и чужое
состояние ведёт к повторному вопросу. Клиент без этой возможности получает
прежний ответ: отказ остаётся отказом, разрушающий вызов исполняется без
вопроса.

Вопрос называет предмет и варианты. Под заголовком идёт по строке на
вариант: что пропадёт при его выборе. Путей проекта, команд раннера и
служебных идентификаторов в вопросе нет. Пароли и другие учётные данные
вопросом не запрашиваются.

Вопрос несёт устойчивый код и структурные данные своего предмета — например,
список сеансов, которые держат базу: клиент может показать по ним свой экран.
Код, данные и для каждого варианта его надпись и то, что пропадёт, идут в
`_meta` формы под ключом `unica/question`. Ответом остаётся одно значение из
перечня вариантов формы. В данных нет учётных данных; соединение базы идёт
без пароля.

Выбранный вариант исполняется в том же вызове: одним вызовом Unica или
несколькими по порядку. Отказ шага останавливает цепочку, следующие шаги не
исполняются. Ответ начинается с выбора человека и называет итог каждого
исполненного шага. Отмена, отказ клиента отвечать, истёкший срок ожидания и
ответ вне вариантов дают прежний ответ без изменений: отказ остаётся отказом,
разрушающий вызов отменяется с `cancelled`.

Спрашивает только исполняемый вызов. Превью (`dryRun: true`) отдаёт прежний
ответ. Вызов, ставший фоновой задачей, получает прежний ответ в результате
задачи. Без ответа человека Unica сама вариант не выбирает и не добавляет к
вызову `force` или другое разрушающее значение.
