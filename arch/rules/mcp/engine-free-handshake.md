# Открытие MCP и список инструментов не запускают анализаторы

`initialize` и `tools/list` не запускают процессы поставщиков анализа кода
и не начинают индексирование исходников. Подключение клиента и обнаружение
доступных инструментов не требуют готовности этих движков.

Правило не запрещает запуск самого сервера Unica. Ленивую подготовку движка
для настоящей операции оно также не отменяет.

`tools/list` не читает настройки рабочего пространства: определения
инструментов не зависят от их эффективных значений. Проверка этой границы
также входит в [сценарии операционных настроек](https://github.com/IngvarConsulting/unica/issues/969).
