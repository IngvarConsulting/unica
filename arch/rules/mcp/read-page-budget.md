# Страница чтения ограничивает число элементов и объём ответа

Для страничных ответов канонической поверхности `limit` по умолчанию равен
20, максимум — 50. Дополнительно действует бюджет страницы 64 КиБ.
Ответ называет причину остановки страницы: число элементов или объём.
Предел транспортного сообщения не заменяет этот бюджет.

Это целевой контракт: текущие инструменты используют разные пределы,
а `check` пока не принимает параметры страницы. Разрыв сохранён в `gap`.
