# Опубликованный аргумент достигает поведения инструмента

Для каждого аргумента публичной схемы существует допустимый вызов,
в котором обработчик читает его и учитывает в результате или действии.
Аргумент не игнорируется и не становится недостижимым из-за требований
к соседним аргументам.

Это не обещает успех любого запроса: несуществующая цель, недоступный
поставщик и недопустимая комбинация значений по-прежнему могут вызвать отказ.
Проверка канонического маршрута по всему опубликованному каталогу пока
не завершена; проверки прежних инструментов её не заменяют.
