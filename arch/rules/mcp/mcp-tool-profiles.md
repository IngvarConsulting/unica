# Версия протокола MCP и объявление Tasks определяют каталог инструментов

Unica предоставляет восемь основных инструментов: `unica.view`, `unica.apply`,
`unica.resolve`, `unica.search`, `unica.check`, `unica.diff`, `unica.run`
и `unica.docs`.

Для `2026-07-28` состав каталога определяет объявление Tasks в конкретном
запросе `tools/list`. С Tasks каталог содержит восемь основных инструментов.
Без Tasks к ним добавляются `unica.task.get`, `unica.task.result` и
`unica.task.cancel`. Прежние версии протокола также получают все одиннадцать.

`tools/call` определяет способ выдачи результата по своим возможностям.
Если вызов использует другой набор возможностей, клиент может запросить
соответствующий каталог. Продолжение доступно в профиле выдавшего его вызова.
