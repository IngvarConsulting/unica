# Наружу дверь MCP даёт только запуск по stdio

Публичная поверхность двери MCP — запуск сервера по stdio. Продукт передаёт
двери подключение к демону и другого от неё не получает. Типы и сущности SDK
за пределы двери не выходят: ни в публичных сигнатурах, ни через re-export
или макросы.

Тестам дверь может открыть внутренности; производственная поверхность
от этого не растёт.
