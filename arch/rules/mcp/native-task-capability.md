# Встроенные задания MCP доступны только клиенту с Tasks capability

В канонической поверхности v0.13 ответ `CreateTaskResult` и методы `tasks/*`
доступны только при протоколе `2026-07-28` и явно объявленной клиентом
Tasks capability. Для прямого запроса это объявление относится к самому
запросу. Метаданные отдельного запроса не повышают legacy-сессию до нового
протокола.

Вызов `2026-07-28` без Tasks в самом `tools/call`, ставший заданием, ждёт
его завершения и отвечает итогом — тем же, что вернул бы `unica.task.result`:
без снимка задания и без ссылки на `unica.task.*`. Пока вызов ждёт, клиенту
с `progressToken` идут `notifications/progress`. Отмена такого вызова
отменяет задание. Вызов уже принят, поэтому ответ не предлагает повторить
его: потерянное чтение задания повторяется для того же задания, а задание,
которое больше не удаётся наблюдать, даёт отказ с исходом `needsHuman`.

Проекция задания, его получение, обновление, отмена и опрос не запускают
предметную операцию повторно.
