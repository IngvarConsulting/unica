# Встроенные задания MCP доступны только клиенту с Tasks capability

В канонической поверхности v0.13 ответ `CreateTaskResult` и методы `tasks/*`
доступны только при протоколе `2026-07-28` и явно объявленной клиентом
Tasks capability. Для прямого запроса это объявление относится к самому
запросу. Метаданные отдельного запроса не повышают legacy-сессию до нового
протокола.

При `tools/call` без Tasks быстрый вызов возвращает свой результат.
Как только демон передал работу заданию, исходный вызов возвращает квитанцию
с `structuredContent.data.task.taskId` и продолжением через `unica.task.result`.
Это правило действует для любой операции, переданной заданию. Сохранённый итог
можно прочитать из нового соединения в той же области работы.

До передачи действуют правила отмены исходного запроса. После передачи разрыв
соединения или отмена ожидания результата оставляет задание доступным по
`taskId`. Отмену самого задания клиент запрашивает через `unica.task.cancel`.

Проекция задания, его получение, обновление, отмена и опрос не запускают
предметную операцию повторно.
