# Ошибка обязательного перечисления называет допустимые значения

Если обязательный аргумент выбирается из закрытого набора, отказ при его
отсутствии перечисляет допустимые значения так же, как отказ при неверном
значении. Агент может исправить вызов без пробного подбора.

Существующий тест `clientMode` проверяет начало сообщения, но не сами
допустимые значения. Содержательная проверка перечислений указана в `gap`.
