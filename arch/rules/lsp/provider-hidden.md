# Ответ LSP не раскрывает поставщика анализа

Ответы и уведомления LSP строятся из модели Unica. Имя поставщика, его
тексты, идентификаторы и форматы артефактов не передаются. Для находки
анализатора поле `Diagnostic.code` сохраняет исходный код его правила,
даже если у Unica нет отдельного текста для этого правила. Поле
`Diagnostic.source` у таких находок имеет значение `unica`, а текст
формулирует Unica.

Замена поставщика не меняет протокол LSP, объявленные возможности и форму
ответов. Коды правил анализатора могут измениться вслед за поставщиком.
Собственные находки Unica, отказы и недоступность поставщика обозначаются
кодами Unica.
