# LSP не пишет в исходники

Ни один запрос LSP не изменяет исходники рабочей области на диске.
Переименование и исправления возвращаются редактору как предлагаемые
правки; их запись в исходники выполняется только через план `unica.apply`
с проверкой ревизии.

Открытый в редакторе несохранённый текст влияет только на ответы LSP
для этого соединения и не становится содержимым исходников.
