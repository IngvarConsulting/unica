# Адрес документа однозначен в соединении

Документ LSP адресуется как `unica://<пространство>/<набор>/<адрес>`.
Пространство выдаёт сервер для каждой рабочей папки соединения; в одном
соединении один адрес указывает ровно на один документ, даже если в разных
папках есть наборы исходников с одинаковым именем.

Адрес с пространством, которое сервер не выдавал этому соединению,
отклоняется и не разрешается в документ другой рабочей области.
Адрес `file://` принимается, если он соответствует документу рабочей
области, и переводится в тот же документ.
