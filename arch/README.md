# Правила продукта Unica

В `rules/` — атомарные обязательства, согласованные владельцем.
Они не являются полным описанием продукта. Отсутствие записи не
отменяет существующие гарантии и их содержательные тесты.

Каждая запись содержит `id`, точные адреса тестов в `check` и саму гарантию.
Правило можно найти по предмету, пути исходника или имени теста через `rg`.
В `docs/arch-v2/` остаются ещё не разобранные документы прежней архитектуры.
История изменений доступна в Git; `docs/arch-v1/` пока остаётся архивом.
