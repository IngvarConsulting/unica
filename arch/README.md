# Правила продукта Unica

В `rules/` — пилот из десяти атомарных обязательств для вычитки владельцем.
Он не является полным описанием продукта. Отсутствие записи в пилоте не
отменяет существующие гарантии и их содержательные тесты.

Каждая запись содержит `id`, точные адреса тестов в `check` и саму гарантию.
Правило можно найти по предмету, пути исходника или имени теста через `rg`.
Прежнее описание сохранено как история в `docs/arch-v2/`; `docs/arch-v1/`
также остаётся архивом.
