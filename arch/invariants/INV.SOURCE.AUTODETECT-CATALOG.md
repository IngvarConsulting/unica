# Автообнаружение идёт по закрытому каталогу раскладок

Рабочее пространство без `v8project.yaml` получает наборы исходников только из
закрытого каталога раскладок, общего для обоих маршрутов дискавери вместе со
списком маркеров корня. Каталог и его записи считаются кандидатами только как
настоящие каталоги без перехода по ссылке; определённо непригодное пропускается,
а отказ, оставивший вопрос без ответа, завершает дискавери ошибкой. Имя набора
совпадает с именем держащего каталога, `main` остаётся за базовой конфигурацией,
пока она его занимает, а листинг каталога входит в происхождение карты.
