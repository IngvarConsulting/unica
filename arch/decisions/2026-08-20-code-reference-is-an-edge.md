# Обращение из кода — ребро того же графа, а не находка поиска

**Решение.** Обращение к объекту метаданных из модуля приходит ребром вида
«код» в ветке «на него ссылаются», рядом со структурными рёбрами. Ребро несёт
адрес модуля и метода, откуда обращаются. Происхождение ребра названо всегда:
структурное доказано выгрузкой, кодовое получено разбором модуля.

**Почему.** Вопрос один — «кто зависит от этого объекта», — и делить ответ по
тому, из чего связь извлечена, значит требовать от вызывающего двух вызовов и
ручной склейки. Лексический поиск этот ответ не заменяет: он не отличает
обращение от совпадения подстроки в комментарии, а имя объекта в коде пишется
языком платформы и склоняется по контексту. Замер соседнего индекса code-index
(0.55): на центральном справочнике 2443 обращения из кода — перечень, который
грепом за один ход не собирается.

**Почему вид ребра обязателен.** Структурная связь и упоминание в коде имеют
разную надёжность: первая либо есть, либо нет, вторая зависит от полноты
разбора. Смешать их без пометки — обещать доказанность там, где её нет.

**Цена.** Ветка становится зависимой от разбора модулей: пока код не разобран,
она отвечает неполно, и эту неполноту обязана называть.
