# Ресурс предлагается для байтов, которых, скорее всего, не попросят

**Решение.** Объёмное и бинарное непонятое содержимое не едет в ответе: вместо
байтов даётся ссылка на ресурс, который сервер отдаёт по чтению. Каталог
ресурсов при этом не публикуется — ссылка приходит в результате, и обнаружение
через перечисление не участвует. Для содержимого, которое вызывающий запросил
явно — код, разобранные структуры, — ссылка не используется: оно едет в ответе
постранично.

**Почему.** Ссылка стоит порядка пятнадцати токенов. Если байты не понадобятся,
сэкономлено всё; понадобятся — заплачено ровно тогда. Обратное направление
измерено и закрыто: чтение ресурса идёт целиком, без постраничности, поэтому
для нужного содержимого оно строго хуже резаного ответа.

**Динамика каталога тут ни при чём.** Замороженный на подключении список
ресурсов мешает обнаружению через перечисление, а не чтению по ссылке; чтение
по ссылке, полученной из содержимого, измерено и работает.

**Цена.** Это объявление новой возможности протокола, а не строчка в ответе:
сегодня заявляются только инструменты. И на одном из хостов самостоятельное
чтение по ссылке не доказано — значит рядом со ссылкой обязана стоять строка,
объясняющая, что это и зачем открывать.
