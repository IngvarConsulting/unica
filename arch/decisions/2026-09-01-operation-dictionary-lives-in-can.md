# Словарь операций писателя живёт в can читаемого узла

**Решение.** Словарь операций `apply` публикуется данными: секция `can`
результата `view`, только по явному запросу `filter.sections`. Элемент —
`{"op", "args": values|items|text|at, "implemented"}`; состав выводится из
одного источника — закрытого реестра операций × применимости к виду узла,
того же, которым сервер валидирует вызов. `can` живёт на предметном узле,
узле-коллекции и корне; отдельный полный каталог не заводится. Вид узла без
вычисленного `can` отвечает на запрос секции typed `unsupported_section`,
промах по ключу аргументов называет принимаемый скелет. Схема `apply`
остаётся плоской: `op` — строка без перечислений и union; словарь операций
в схему не возвращается ни объединением, ни закрытым перечнем имён.

Довод ADR-0025 §4 о properties-only хостах получает ответ переносом
носителя: результат вызова доходит до модели дословно на каждом хосте
гарантированной матрицы поддерживаемых протоколов, тогда как рендеринг
схемы хостозависим — что и было посылкой §4. Предметный тип на входе держит серверная валидация
закрытым реестром с восстановимым отказом.

Первая фаза словаря — виды metadata-семейства и корень — реализована вместе
с записью; остальные семейства заполняют `can` своими вертикалями. Прогон
задач 1–2 каталога метрики «токены на решение»
(`docs/design/2026-08-17-token-cost-task-catalog.md`) — токены и first-call
против baseline без `can` — остаётся условием приёмки развилки; ухудшение
first-call возвращает развилку владельцу.

**Почему.** Объединение в схеме измерено в 4 715 токенов только на ветвях
против ограждения ≤2000; закрытый перечень имён стоит +335 токенов в каждом
профиле каталога, инвалидирует кешируемый список и раздваивает источник
словаря, а его хост-гарантия не проверена. Словарь в данных уже доказан
живым прецедентом `run {}` и не трогает каталог.

**Цена.** Первый вызов мутации в эпизоде требует `view` с запросом `can`
(136–370 токенов на узел по замерам формы); полнота словаря появляется
поэтапно вместе с вертикалями семейств, и до заполнения вида агент получает
`unsupported_section` вместо словаря.
