# Публикация выражается зависимостями одного конвейера

**Решение.** Stage, неизменяемый tag, проверки чистой установки и обновления,
затем promotion образуют один линейный проход. Каждая стадия имеет
идемпотентный выход для повторного запуска; каталог ждёт обе потребительские
проверки, а тег не перемещается.

**Почему.** Независимые конвейеры способны молча остановиться между передачами
состояния или продвинуть каталог раньше проверки. Явные `needs` делают границу
отказа наблюдаемой в одном run.

**Цена.** Повтор использует уже опубликованное состояние и поэтому обязан
доказывать его идентичность вместо безусловного перезапуска стадии.
