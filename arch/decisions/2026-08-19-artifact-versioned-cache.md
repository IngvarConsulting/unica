# Артефакт кешируется по своей версии, а не по версии плагина

**Решение.** Ключ установки — имя артефакта, его собственная версия и
неизменяемая идентичность поставки:
`<артефакт>/<версия>--<sha256 архива>/<цель>`. Выпуск плагина, не менявший
поставку инструмента, ничего про него не докачивает. Другая сборка под той же
версией получает другой корень и не перезаписывает байты работающего процесса.
Частичная загрузка сохраняется и продолжается диапазоном в следующей сессии.

**Почему.** Ключ по версии плагина объявлял холодным весь кеш при любом
обновлении, хотя инструменты живут своим темпом. Ключ только по версии имел
обратный дефект: повторная сборка с новыми байтами могла попасть в уже занятый
корень. Версия убирает лишние загрузки, сумма отделяет разные поставки.

**Один архив — один раз.** Два инструмента RLM делят один файл с одной
контрольной суммой; ключ по артефакту делает это видимым и исключает двойную
загрузку.

**Цена.** Удалять по версии плагина больше нельзя. Сборкой мусора владеет
`DEC.2026-08-19.RETENTION-BY-ARTIFACT`: она удерживает две свежайшие поставки
каждого артефакта и намеренно не считает ссылки от версий ядра. Откат за пределы
этого окна может потребовать повторной загрузки; взамен обновление перестаёт
стоить полной перекачки.
