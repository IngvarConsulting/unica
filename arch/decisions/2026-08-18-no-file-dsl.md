# Файловый DSL не входит в публичный контракт

**Решение.** Схема «декомпиляция → правка файла → компиляция → валидация»
снимается целиком. Аргументы `JsonPath` и `DefinitionFile` исчезают вместе с
парами `compile`/`decompile`. Массовое изменение остаётся — типизированным
массивом элементов внутри одной операции, а не документом на внешнем языке.
Форматные спецификации описывают внутренний эмиттер, а не язык вызывающего.

**Почему.** Полная пересборка артефакта теряет байты, которые форматный
контракт обязан сохранять: порядок узлов, объявления префиксов пространств
имён, BOM, наблюдённый стиль перевода строки. Это вопрос целостности данных, а
не эргономики. Вдобавок схема MCP не проверяет внешний язык до вызова, и ошибка
в нём обнаруживается после записи.\n
