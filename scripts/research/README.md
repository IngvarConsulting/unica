# Исследования

Исследование отвечает на конкретный вопрос о платформе или формате.
Сохраняйте воспроизводимые входы, версии и метод; полезный результат —
в спецификации или фикстуре, которую использует продукт либо его проверка.
Повторяйте исследование при смене предпосылок. Отдельный реестр исследований
не нужен. Проверка того, что код по-прежнему соблюдает найденное свойство,
остаётся обычным тестом — её порядок описан в
[unica-testing](../../.agents/skills/unica-testing/SKILL.md).

Код исследований собирается только с фичей `research` и ни в одни ворота
конвейера не попадает. Запуск — обёртками отсюда: у каждой записан вопрос,
метод, входы и команда, чтобы исследование можно было повторить намеренно.

| Обёртка | Вопрос | Результат |
| --- | --- | --- |
| `xml-corpus.sh` | какие байты пишет платформа 8.3.27 (экспорт 2.20) | корпус XML в дереве, манифест версии 2 |
| `cf-init-checkpoint.sh` | как выглядит дерево `cf init` на 8.3.27 | снимок-улика вне репозитория |
| `platform-event-catalog.sh` | какие события платформа знает по своей справке | `platform-event-catalog` в исходниках |
